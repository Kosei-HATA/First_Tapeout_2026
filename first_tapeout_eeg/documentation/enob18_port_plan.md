# ENOB18 移植計画（行為探索の結果に基づく、フェーズ 2）

2026-10-02。入力: gf180/behavioral/ の掃引・頑健性結果。

## 選定構造（行為レベルで 110.24 dB 達成）

- **2 次 SC ΣΔ（Boser-Wooley 交互相、sdm3 係数 a1=d1=2, a2=0.5, d2=1）＋ 4 bit 量子化（15 レベル）＋ fs=512 kHz（OSR=2560）**
- ディザなし（効果限定的、PN は悪化）
- 参考: 1 bit 同一構成は 70 dB 台（実測 70.98 dB と行為モデル 70.36 dB が一致）

## 移植時の必須要件（頑健性評価より）

1. **DEM（動的素子マッチング）必須**: 4 bit DAC のステップミスマッチ 0.1 % で 75〜84 dB に劣化、1 % で 55〜65 dB。バレルシフタ（DWA）等でミスマッチをシェイプすること。DEM 込みの行為検証を先に行うこと
2. **フラッシュ量子化器（15 コンパレータ）**: strongarm 15 個 or 共有化。ヒステリシスは行為評価で無害（123.6 dB）
3. **512 kHz クロック**: 現行 clkgen の 256 kHz マスタでは不足。ベンチでは外部供給、最終的には clkgen RTL の更新が別途必要（SPI IF 計画と整合させる）
4. **積分器**: GF180 実測 kappa=1e-3 で 96〜109 dB（振幅依存）。DEM 成功が前提
5. **読み出し**: サーモメータ 15 ラインの多数決 → scripts/sdm_mb_bitstream.py（--ncols 15、1 bit 既存データで検証済み）

## フェーズ 2 の作業順序

1. DEM（DWA）込みの行為確認（ミスマッチ 0.1〜1 % で 110 dB 級を維持すること）
2. トランジスタ移植: gf180_sdm3 を母胎に 4 bit 化（量子化器・DAC・DEM ロジック）
3. TT ショートラン（3 サイクル）でスクリーニング → フルラン（322.5 ms）で確定
4. 完了条件: TT フルラン SNDR ≥ 110 dB を ngspice 実測、gf180_feasibility.md に記録
