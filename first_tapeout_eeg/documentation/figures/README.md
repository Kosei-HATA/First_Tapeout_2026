# 図の置き場所

`documentation/` の文書が使う図。**どの版のチップの図かが分かるように、版ごとのフォルダに分けてある**（10/26）。

- GF180 の版は、文書の「N 回目のチップ」（組み立ての回）と同じ番号で `rN_<日付>` とした。10/23 の最初の組み立てが r0、10/24 の D6 の直しが r1、今は r6。
- 1 つのフォルダには 1 つの版の図だけを置く。結果が変わる版では、新しい `rN_<日付>/` に図をひとそろい描き直す（前の版のフォルダは上書きしない）。
- 可視化、レイアウト、E2E の図は、ファイル名にも版が入る（`gf180_viz_r6_NN_*.png`、`gf180_layout_r6_NN_*.png`、`gf180_e2e_pex_r6_N_*.png`）。図の右上にも版を書いた。
- 各フォルダの `README.md` に、その版のコミット、precheck のタグ、GDS の sha256、図を作ったスクリプトを書いた。
