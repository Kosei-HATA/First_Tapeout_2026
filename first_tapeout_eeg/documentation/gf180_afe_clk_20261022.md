# AFE のクロックドライバ（B8 の AFE 側）（2026-10-22）

RTL の CHOP、CHOP_OUT、CHOP_BLANK から、AFE のチョッパの相、電極オフセット DAC の相（OFPH）、リセットを作る回路を設計した。ADC の比較器のストローブは量子化器の中で駆動する（`gf180_quantizer_20261022.md`）。DAC1 の D／DB の駆動（B3）は別に設計する。

- ネットリスト：`gf180/tapeout/afe/eeg_afe_clk.spice`（`eeg_afe_clk`）
- 単体の確認：`gf180/tapeout/sim/afe/clk_check.py`（TG のゲート容量に相当する負荷をつなぐ）
- AFE と組み合わせた確認：`gf180/tapeout/sim/afe/afe_offset.py --clkdrv`
- 結果の置き場所：`gf180/tapeout/sim/afe/runs/`（git の対象外）

## 機能

| 出力 | 作り方 | 負荷 |
|---|---|---|
| CIA／NCIA、CIB／NCIB（入力チョッパ） | CHOP（CHOP_EN が低いときは相 A に固定）から、交差結合の NOR と遅延段（長チャネルのインバータ 4 段）で非重複にする。CIA と NCIA は相補の信号から同じ 4 段の連鎖で駆動する | NMOS のゲート約 16.6 pF、PMOS のゲート約 33 pF（m = 256 の TG 2 個） |
| CDA／NCDA、CDB／NCDB（出力チョッパ） | CDA = CHOP_OUT かつ CHOP_BLANK でない、CDB = CHOP_OUT でなく CHOP_BLANK でもない | 約 0.3／0.6 pF |
| OFPH（オフセット DAC の相） | CIA でセット、CIB でリセットする SR ラッチ。不感時間の間は値を保つので、入力 TG が新しい相で閉じる時刻に変わる | 約 0.2 pF |
| RST | AFE_RST の緩衝 | リセットスイッチのゲート |

- 電源は AVDD／AVSS。入力 TG のゲートの電位は信号の経路に直接結合するので、デジタルの電源には載せない。

## 単体の特性

| 項目 | typical、27 °C | ss、85 °C | ff、−20 °C |
|---|---|---|---|
| 入力チョッパの不感時間（一方の TG が完全に切れてから他方が導通し始めるまで） | 4.41 ns | 5.95 ns | 3.31 ns |
| CIA と NCIA の時間差（50 %） | 0.28 ns | 0.38 ns | 0.23 ns |
| CIA の立ち上がり（10〜90 %） | 1.06 ns | 1.35 ns | 0.85 ns |
| NCIA の立ち下がり（90〜10 %） | 1.33 ns | 1.73 ns | 1.07 ns |
| CHOP の端から CIA の 50 % まで | 7.17 ns | 9.46 ns | 5.55 ns |
| OFPH の切り替え（CIA／CIB の 50 % の後） | 0.61 ns | 0.80 ns | 0.48 ns |
| ブランキングの終わりから CDB の 50 % まで | 0.52 ns | 0.67 ns | 0.41 ns |
| ブランキング中の CDA／CDB の最大 | 0 V | 0 V | 0 V |
| 1 回の切り替えで電源から流れる電荷 | 178 pC | 179 pC | 174 pC |

- 不感時間は、AFE の解析で仮定した 5 ns に近い。
- 入力チョッパの端は CHOP の 6〜10 ns 後に来る。CHOP_OUT = CHOP（CHOP_DLY = 0）でも、ブランキング（1 MCLK 前から）の中に入る。

## AFE と組み合わせた確認

`afe_offset.py --clkdrv`：RTL と同じ形の CHOP／CHOP_BLANK でこのドライバを動かし、AFE（オフセット DAC と DC 経路を含む）につないだ。片側 R_s 100 Ω、ブランキング 15 MCLK。

| オフセット | 範囲 | 残差（入力換算） | ブランキング後の出力の乱れ（p-p） | 増幅器の最大振幅 |
|---|---|---|---|---|
| 0 | 4 | 0 | 0 | 0 |
| +30 mV | 1 | +0.11 mV | 65 mV | 0.94 V |
| ±300 mV | 4 | ∓0.11 mV | 64 mV | 1.77 V |

- 理想のクロック（不感時間 5 ns）のとき（60 mV）とほぼ同じ。OFPH の時刻も、オフセットの打ち消しに十分合っている。

## 残っていること

- **電源**：1 回の切り替えで約 178 pC（大半は入力 TG のゲート）を、1〜2 ns で流す（ピーク約 100 mA）。ドライバの近くに AVDD のデカップリングを置き、AVDD のパッドからの経路を短くする。チョッパと同期した決まった形の乱れなので、帯域内の雑音にはならないが、大きさは PEX で確かめる。
- **レイアウト**：ドライバを入力 TG の近くに置き、P 側と N 側への配線を対称にする（TG の電荷注入の非対称が、チョッパ由来の残留オフセットになる）。
- **DAC1 の D／DB の駆動（B3）**：系統的なスキュー 5 ps 以下。別に設計する。
- **CHOP_DLY と遅延の関係**：入力チョッパの遅延（6〜10 ns）と AFE の遅れを合わせた最適な CHOP_DLY を、チョッパ動作の解析で決める。
