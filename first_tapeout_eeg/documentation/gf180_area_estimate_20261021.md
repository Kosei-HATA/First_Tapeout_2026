# GF180 面積見積もり（判断ゲート 1、2026-10-21）

独立環境（Codex）の現候補を対象に、素子を積み上げて Half スロットに収まるかを判定した。

## 対象

| ブロック | 中身 |

| AFE | CCIA、利得 318 系。M2 コア、Cin 636 pF／側、Cf 2 pF、Cpf 2.10 pF、入力 TG m=64、64 kHz チョップ |
| ADC | CT 2 次・5 bit（利得 10 系）。RIN 9375 Ω、DAC1 300 kΩ × 31、C1 680.5 pF／側、R21 1 MΩ、DAC2 106.7 MΩ × 31、C2 1.95 pF |

- **素子数の出典**：`ct_candidate/afe_adc_cap2_direct_threshold1u_20261020/` の接続デッキ。
  - ファイルは `circuit.spice`、`afe_model.spice`、`otas.spice`、`quantizer.spice`。
  - AFE の回路は 10/21 の cpf210 と同一で、違いは Cpf だけ（2.06 pF → 2.10 pF に置き換えて集計）。
- **再現方法**
  - 集計：`python3 gf180/size_estimate_ccia_ct.py <デッキのディレクトリ>`

## 判定

- **現状の値のままでは収まらない。**
  - DAC2 の単位抵抗（106.7 MΩ × 62 本）だけで約 4.4 mm² になり、Half のコアとほぼ同じ大きさになる。
  - ADC デッキでは DAC を理想電圧源と 1 本の等価抵抗で表しているため、この問題がシミュレーション上は表に出ない。
- **DAC2 を作り直せば、収まる可能性はあるが余裕がない。**
  - 合計は 3.5〜5.5 mm²で、Half Height の 70〜110 %、Half Width の 79〜124 % にあたる。
  - 面積も縦横比も有利なため、Half Height を推奨する。Half Width はコア幅が 1.05 mm と細く、差動対称に配置しにくい。
- **Full は選べない。** Run 3 では売り切れと告知されている。
- **面積の観点では、利得配分は ×318 が有利。**
  - ×31.8 の配分では積分容量が 1.95 nF／側になり、C1 だけで約 2.2 mm² を占める。
  - 現候補の ×318（C1 0.76 mm²、Cin を 2 倍にした分を差し引き）と比べて約 1.1 mm² 大きい。

## 面積を減らす手段（効果の大きい順）

1. **DAC2 の作り直し（必須）**
   - R・C の積を保ったまま C2 を約 93 pF／側にすると、0.22〜0.26 mm² になる。
   - 10/22 に、段 2 を 10 倍スケールして MOS の電流ステアリング DAC にする案を採用した。面積は 0.034〜0.049 mm²。
   - 性能の確認は `gf180_large_resistors_20261022.md` を参照。
2. **C1 を半分にする（340 pF／側、RIN と DAC1 は 2 倍）**
   - 0.38 mm² 減る。
   - ADC の抵抗雑音は電極換算で 0.79 → 1.11 nVrms に増える（予算全体は 5.88 nVrms）。
   - 1/4 にすると 0.57 mm² 減り、雑音は 1.58 nVrms になる。
3. **Cin を 318 pF／側に戻す**
   - 0.36 mm² 減る。
   - ただし Codex が cap2 を選んだ理由（固定寄生容量の比を下げる）とのトレードオフになる。
4. **デカップリング容量を MIM の下に置く**
   - 0.1〜0.25 mm² 減る。
   - MIM 下の配置ルールと、下層との結合を確認する必要がある。
5. **独自パッドリングにする**
   - 使える面積が約 9.6 mm² まで増える。
   - 代わりに、パッケージ品（Chip on Board）は使えなくなる。

## 前提と限界

- **MOS**：pcell の外形（ガードリングなし、nf=32 単位にまとめる前提）に 1.5〜2.5 倍を掛けた。
- **MIM**：2.0 fF/µm² に 1.12〜1.25 倍（単位容量アレイ・ダミー分）を掛けた。
- **抵抗**：3 kΩ/□、W=1 µm（DAC1 は 2 µm、RIN は 5 µm）、配線ピッチ 2W で計算した。
- **未設計ブロック**：量子化器、スイッチ、バイアス・基準、DC サーボ、デカップリング、デジタルは、いずれも見積もり幅で計上した。
