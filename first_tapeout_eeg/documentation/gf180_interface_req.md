# GF180 (wafer.space) 版 外部インターフェース要件

2026-09-17 ユーザー指示: caravel 版と違い wafer.space スロットは全てユーザー領域
（管理 SoC なし）なので、外部との通信手段を設計に含めること。

## 方針: SPI スレーブ（最小構成）

- **SPI スレーブ RTL**（新規・プロセス非依存の Verilog）を追加:
  - レジスタマップ: ゲイン選択（x8/16/32/64）、RST、（将来）チョップ/デシメ設定
  - 読み出し: CIC デシメータ出力（24 bit）を SPI から読む、または BIT を直接 GPIO へ
- **パッド見積もり**: SPI 4 本（SCLK/CSB/MOSI/MISO）＋ BIT 生出力 1〜2 本＋電源。
  Quarter スロット（48 I/O）でも余裕
- **クロック**: 管理 SoC が無いので 256 kHz マスタは外部パッド供給、
  または SPI クロックからの分周（最終決定は rev2 デジタル統合時）
- **面積見積もり**: SPI+CIC+clkgen のデジタル部は GF180 で ~0.05-0.15 mm² 級
  （マクロ面積見積もりへの影響は小さいが、サイズ見通し表に行を追加すること）
- ESD/パッドリングは wafer.space のガイドライン（カスタムパッドリング可、
  デフォルトパッドリングは core area 内）に従う
