# 実際に近い条件での立ち上がりと性能（管理表 D7、10/27〜）

10/27 に、立ち上がりの図が理想化した条件のもの（解いた動作点から始め、理想のバイアスと電源、共通の理想グラウンド、typical だけ）だったことについて、ユーザーから次の指示があった：「実際にそんな挙動をするかというのが大事」「製造ばらつきなんかも考えると monte-carlo 法とかも含めるべき」「立ち上がりに限らず、性能等の評価でも一緒です」。この文書は、その条件で立ち上がりと性能を測り直した結果をまとめる。チップは 6 回目（r6、10/26）。10/27 夜に組み直した GDS は r6 とマスクが同じ（XOR で全層一致）なので、抽出も同じ。

## テストベンチ

| スクリプト | 何を測るか |
|---|---|
| `gf180/tapeout/pex/afe_startup.py` | AFE の電源投入からの過渡（power：リセットのまま、start：RTL の順序で解除まで） |
| `gf180/tapeout/pex/afe_chip_noise.py` | チップの実際の動作点での AFE の雑音（`pex_afe.py` の noise と同じ方法） |
| `gf180/tapeout/pex/pex_chipnets.py` | チップの配線の抽出（結果と方法は `gf180/tapeout/pex/runs/chipnets/README.md`） |
| `gf180/tapeout/pex/e2e_startup.py` | 電極から ADC の符号までの電源投入からの通し（AFE と ADC はトランジスタのまま） |
| `gf180/tapeout/pex/adc_flicker.py` | ADC のポリ抵抗（RIN、DAC1、基準電圧のフィルタ）のフリッカ雑音。PDK の式の ngspice での確認と、行動モデルのコード列を RTL の DWA に通した計算（11/12） |

入っているもの：

- 電源投入から：AVDD、DVDD、外付けの基準（1.9／1.4 V）が 1 ms で 0 から立ち上がる。すべての節点が 0 V から始まる（`uic`）。
- 基板（仮定、基板はまだない）：レギュレータの出力抵抗、10 µF と 100 nF（ESR／ESL 込み）、VCM の容量 10 nF／100 nF／1 µF。ボンディングワイヤは接続したパッド 1 個に 1 本（2 nH、0.1 Ω）。
- パッドリング：PDK の IO のネットリスト（asig_5p0 47 個、dvdd／dvss 各 8 個、コーナー 4 個）。
- チップの配線（`pex_chipnets.py`、穴埋めのあとのチップ、金属抵抗は typical）：接続した 13 個のアナログパッドのパッドセル（内部の Metal2、ESD ダイオード、容量）、AVDD／AVSS の網と 75 個のデカップリング、ブロックの間の配線（バイアス線、VCM、電極のストラップ、OUTP／OUTN、基準電圧）とその容量、切り替わる線との結合。ブロックはそれぞれ自分のピンで電源とグラウンドにつながる。afe_top の中の電源レール（端子からテールまで AVSS 0.746 Ω、AVDD 0.123 Ω）は見積もりで、一括の抵抗として入れた。
- 抽出したブロック：afe_top（素子と寄生容量、入力の信号経路の配線抵抗）、eeg_bias、eeg_ref。トリムはレジスタのリセット値（AFE_IBIAS code 2）で、`--ibias 3` のときはファームウェアが RESET_N の解除の 20 µs あとに AFE_IBIAS を 3 に書く。
- RTL の順序：RESET_N が low の間はチョッパが止まり、AFE_RST = 1。RESET_N の解除でチョッパが 128 kHz で動き出し、AFE_RST はソフトウェアが 5 ms で下ろす（モンテカルロでは解除をチョッパの任意の位相に置く）。デジタルの出力は DVSS と DVDD の間で振れる。
- ADC：入力抵抗（片側 18.75 kΩ）、基準の負荷（27.2 µA）、電源電流 4.7 mA を、それぞれ ADC のピンに置く（`e2e_startup.py` では ADC そのもの）。
- ばらつき：モンテカルロ（PDK の statistical：工程と素子ごとのばらつき。`.options seed` で再現できる）。MIM と poly 抵抗の素子ごとのばらつきは PDK にないので、仮の係数（MIM 1.41 %·µm、抵抗 3 %·µm）で入れた（抵抗の分は 10/28 に直した。下の雑音の節）。AVDD ±5 %。温度は 27 °C だけ（ユーザーの指定）。

残っている単純化：基板の値は仮定。ブロックの抽出は容量だけで、ブロックの中の抵抗は afe_top の電源レールの見積もりと入力の信号経路のほかはない。テストマルチプレクサは入れていない。デジタルブロックの電源電流とそのパッドはない（9 回目の通しの 1 つのチャンクに入れて確かめた。下の「デジタル側」の節）。MOS 容量は線形の代わり（`moscap_lin.spice`）。雑音は過渡では入れていない。

数値上の扱い（結果に効かないことを確かめた）：

- ボンディングワイヤの L に並列に 20 Ω（高周波の損失）を入れた。減衰がないと、最初のチョッパの切り替わりで ngspice が「Timestep too small」で止まる（500 Ω、2 kΩ でも後の切り替わりで止まる）。20 Ω と 100 Ω の差は、チョッパ周期の平均で 0.002 µV。
- 最大の時間刻みは 100 ns。10 ns との差は、チョッパ 10 周期の平均で 0.003 µV（1 µs では 0.14 µV）。

## チップの配線で分かったこと（10/27 夜）

- **バイアス回路と AFE のグラウンドがずれる。** eeg_bias は VBN を自分の AVSS に対して作るが、AFE のテールの AVSS はそれより 25.3 mV 高い（チップの配線で 13.7 mV、afe_top の中のレールで残り）。テールの VGS が 25 mV 小さくなり、AFE の電流は 18.3 mA になる（共通の理想グラウンドなら 22.6 mA、−19 %）。AFE_IBIAS の 1 段（code 2 → 3 で VBN +24.4 mV）とほぼ同じ大きさ。
- **電極のパッドセルの抵抗が抜けていた。** asig_5p0 の内部の Metal2 が 1 パッド 1.27 Ω、2 並列で電極 1 本あたり 0.636 Ω。10/24 以降の入力経路の配線抵抗（`pex_afe.RIN_EXTRACTED`）は、パッドの上の Metal5 からチョッパまでで、これを含んでいなかった（10/22 の予算 v1 では見込んでいた）。含めると片側 1.27／1.33 Ω、雑音 2.07 nVrms（それまで 1.48）。
- ADC での基準電圧は 478.6 mV（eeg_ref の出力で 489.6 mV、名目 493.1 mV）。eeg_ref から ADC までの配線（190〜200 Ω）に ADC の基準電流が流れる。
  - 10/29 に直した：この値は、ADC の基準の負荷を、C1 を半分にする前（10/23 まで）の 27.2 µA としたもの（`afe_startup.py` の `RADC` 18.4 kΩ）。DAC1 の素子の抵抗が 2 倍になった今の ADC は約 16 µA を引く。
  - トランジスタの ADC を入れた通し（`e2e_startup.py`、r6、変換の最初の 1 ms）では、ADC での基準電圧は 487.7 mV（eeg_ref の出力 494.0 mV、外の基準 500 mV、基準の電流 ±16.3 µA）。
  - ADC の DC の利得は、理想の 500 mV の基準に対して +2.9 %。そのうち 2.5 % が基準の降下（eeg_ref のフィルタで 1.2 %、チップの配線で 1.3 %）で、残りがループの利得（1.004）。一定の利得の誤差で、SNDR には効かない（DAC1 の基準電流は符号によらない、B3）。
  - AFE だけの結果（雑音、立ち上がり）はこの負荷にほとんどよらないので、回し直していない。`RADC` は 10/30 に今の ADC の値（29.9 kΩ）に直した。この値を使うのは 9 回目の配線で回した起動の結果から。
- 電源は AFE のテールで 3.210 V、バイアス回路で 3.244 V（レギュレータは 3.3 V）。AVDD の電流は 23.8 mA（ADC の 4.7 mA を含む）。

**11/9 の見直し：上の総残差は、パッドとストラップを二重に数えている。**

- 3.37 nVrms の内訳は次の 3 つ。
  - ADC 側 2.93 nVrms

|---|---|---|
| 2 | 6.35 nVrms | 16.39 bit（約 16.36） |

  - トランジスタのループの計算（8 ms）では、−110 dBc（2.1 nVrms）より下が見えていない。
  - PDK の抵抗のモデルは電圧係数が 0 なので、RIN と DAC1 のポリ抵抗の非線形は計算に入らない。
  - ADC の歪みが −110 dBc なら 16.47 bit、−120 dBc なら 16.56 bit（11/12 に上の直しで計算し直した。前は 16.49、16.57 bit）。16.5 bit には、約 −111.4 dBc より良い必要がある。
  - **11/15：OTA の分は −150 dBc より小さかった**（抽出した OTA の静的な伝達を、フルスケールの積分器の振れに当てた。図 36、下の「ADC の OTA の非線形と DAC1 のジッタ」）。残るのはポリ抵抗の電圧係数で、実機でしか確かめられない（許容は vc2 で約 300 ppm/V²。11/17、図 43）。
- **ポリ抵抗の雑音（11/12 の追記。後輩の Test-2-4 の検証で分かったことを、こちらでも確かめた）：**
  - ngspice で PDK の ppolyf_u_1k をそのまま使うと、本体の抵抗の式に v() があるため B 電源になり、熱雑音もフリッカ雑音も出ない。ADC の RIN の 1 単位（300 kΩ）で確かめると、雑音は 4kTR の 2.6 %（端子の抵抗の分だけ）だった（`res_typical`、m = 1 でも 16 でも同じ）。
  - 上の AFE の値（モンテカルロ）は、本体の式を定数にした `afe_startup.res_mm` を使うので、この問題はない。同じ 1 単位で、電流 0 では 4kTR と一致し、電流を流すとモデル表のフリッカ雑音 KF·|I|／(f·L·W)（KF 2.62e-26、AF 1、L と W は m）と 0.1 % 以内で一致した。
  - ADC の抵抗の熱雑音は 4kTR の手計算なので、これも問題ない。
  - ADC のポリ抵抗のフリッカ雑音は、それまでの予算に入っていなかった（後輩の報告書も未評価）。11/12 に評価した（下）。

**ADC のポリ抵抗のフリッカ雑音（11/12。`gf180/tapeout/pex/adc_flicker.py`、図 33 `documentation/figures/gf180/r10_20261109/viz/gf180_viz_r10_33_adc_poly_flicker.png`）**

- **PDK の式。** ppolyf_u_1k の本体は S_I = KF·|I|^AF／(f·L·W)（KF 2.62e-26、AF 1、L と W は実効の寸法で m）。
  - `res_mm`（ばらつきを切って typical）での ngspice の .noise と 0.06 % 以内で一致した（RIN の 1 単位、0.03〜3 µA）。
  - 0.41 µA の 1 単位で、10 Hz で 586 nV/√Hz になる。熱雑音は 70 nV/√Hz。
- **扱い方。** 抵抗のフリッカ雑音は抵抗値のゆらぎで、雑音電流は −I(t)·δR/R になる（Coram、McAndrew、Gullapalli、Kundert、"Flicker Noise Formulations in Compact Models"、IEEE TCAD 2020）。
  - 同じ論文は、PDK の |I|^AF の形を電流の向きが変わる使い方に当てはめると、直流のような 1/f が誤って出ることを示している。また、AF を 2 以外にする物理的な根拠はほとんどない、としている。
  - そこで予算には「モデル B」を使う。δR/R の大きさを PDK の式から電流 I_cal でとり、各抵抗のその時々の電流に掛ける。I_cal は DAC1 の列の電流 0.41 µA で、RIN のフルスケールの電流とも同じくらい。
  - PDK の式を瞬時の電流にそのまま当てはめる形（モデル A。PDK のモデルで周期的な雑音解析をするとこうなる）は、比べるためだけに載せる。
- **DAC1。** 抵抗は VREFP／VREFN につないだまま（ステアリング型）なので、各列にはコードによらず一定の 0.41 µA が同じ向きに流れる。11/12 の初めに「向きはフレームごとに変わる」と書いたのは誤りで、変わるのは行き先（OUTP か OUTN か）だけ。
  - PDK の式は、この直流の電流でそのまま使える。その雑音を、切り替えのスイッチが素子ごとに ±1 で振り分ける。
  - DWA（`eeg_dwa.sv`）では、各素子の選ばれ方の平均がコードに一致する。そのため、帯域内に残るのは信号に比例する分だけになる。
  - 行動モデルのコード列（`rtl/model/ct2_codes.py`、入力に 50 µVrms の白色雑音、4.1 s）を RTL と同じ DWA に通した。入力がないときは 0.03 nVrms だった。
  - サーモメータ（DWA_EN = 0）なら、入力がなくても 5.27 nVrms になる。DWA_EN のリセット値は 1 で、ファームウェアは変えないこと。
- **RIN。** 信号の電流が流れるので、これも信号に比例する。
- 合わせると、ADC の利得（RIN と DAC1 の比）の 1/f のゆらぎになる。外付けの基準電圧の雑音と同じ種類で、予算でもフルスケールで数える。

| 電極の入力（nVrms、0.5〜100 Hz） | RIN（B） | DAC1 | 計（B） | RIN（A） |
|---|---|---|---|---|
| なし（電極を短絡） | 0 | 0.03 | 0.03 | 0 |
| 直流 153 µV（オフセット DAC の残りの最大） | 0.84 | 0.43 | 0.94 | 2.18 |
| 正弦波 94 µV pk（フルスケールの 10 %） | 0.37 | 0.19 | 0.42 | 1.34 |
| 正弦波 943 µV pk（フルスケール、10 Hz） | 3.71 | 1.85 | 4.15 | 4.25 |

- **フルスケールの ENOB。** 5.60 nVrms に 4.15 nVrms を二乗和で足すと 6.97 nVrms で、16.26 bit になる。**16.5 bit に届かない。** モデル A では 4.63 nVrms、16.19 bit。
  - ただしこれは、PDK の式が 0.41 µA でも正しいとした場合。
  - AF = 1 なので、PDK の正規化した大きさ KF／I は電流が小さいほど大きくなる。これは抵抗の物理（大きさは電流によらない）と合わない。同じ抵抗を幅の方向に並列に分けると雑音が変わる形でもある。
  - PDK の文書は、1/f の測定条件を MOSFET についてしか書いていない（GF180MCU PDK の 2.3 節）。どの電流の範囲で合わせた式かは分からない。
  - PDK の式が 2.16 µA より上でしか成り立たず、それより下では大きさが一定なら、フルスケールでも 16.5 bit に届く（図 33 (b)）。どちらなのかは、測らないと決まらない。
- **EEG で普通の入力では影響は小さい。** フルスケールの 10 % 以下の信号、またはオフセットの残り 153 µV 以下なら 1 nVrms 以下で、総残差は 5.60 → 5.68 nVrms 以下にしかならない。
- **直す場合の候補（PDK の大きさを 0.41 µA でとった場合）。**
  - RIN と DAC1 の両方を ppolyf_u（350 Ω/sq、AF 1.79）にする。
    - 幅 1 µm の 1 本（857 µm）なら、雑音は 0.053 倍で 16.57 bit。同じ抵抗値で抵抗の面積は約 2.8 倍になる（RIN と DAC1 の本体は今 9,300 µm² と 36,100 µm²で、約 81,000 µm² 増える）。
    - ADC に収まる形として、幅 0.8 µm の 2 本を直列にする案を調べた（下の「RIN と DAC1 を ppolyf_u に替える案」）。雑音は 0.069 倍で、同じく 16.57 bit。
    - RIN／DAC1 の比を同じ種類の抵抗で保つため、両方を変える必要がある。
    - DAC1 の切り替えの節点の容量が増えるので、偶成分（今は −0.0014 fC）を確かめ直す必要がある（下の案で確かめた）。
  - ppolyf_u_1k のまま面積を 4 倍（582.56 × 2 µm）にする。0.50 倍で 16.48 bit。
  - どちらも ADC のレイアウトを作り直し、DRC／LVS、PEX、通しのシミュレーションをやり直すことになる。
- **チップで確かめる方法。** 電極に低雑音の直流（フルスケール近く）を入れ、入力が 0 のときと DATA の 1/f の床を比べる。
  - 床が直流に比例して上がれば、利得のゆらぎ。比例の係数から、実際の大きさが分かる。
  - オフセット DAC で直流を作ると、AVDD の雑音も同じ比で入る。外の直流源のほうがよい。
- **ほかの抵抗。**
  - 基準電圧のフィルタ抵抗 R_f（ppolyf_u、2 × 7 µm、30 µA）：VREFP − VREFN に 39 nVrms で、外付けの基準電圧に求める 375 nVrms の約 1/10。フルスケールで 0.052 nVrms。
  - バイアス、VCM の分圧、量子化器のはしご、R21：同相か、ループの中か、第 1 積分器のあとなので、無視できる。
  - RIN の同相の直流電流：9 回目の通しで、入力と仮想接地の同相の差は 0.06〜0.17 mV。単位あたり 1 nA 以下で、無視できる。
  - オフセット DAC の駆動抵抗：電流はチョッパの切り替えのあとに流れるだけで、半周期の中で落ち着くので効かない。

## 立ち上がり（電極 0 V、VCM の容量 10 nF）

## VCM の容量と解除の時刻（基板とファームウェアへの要求）

VCM の外付け容量を大きくして、5 ms で解除した場合（typical）：

| VCM の容量 | 解除の時点の VCM | AFE |
|---|---|---|
| 10 nF | 1.650 V | 上の結果 |
| 100 nF | 0.959 V | 動くが、出力は −0.10 mV でゆっくり動く |
| 1 µF | 0.154 V | 止まったまま（AVDD の電流 7 mA） |

5 ms で解除できるのは 10 nF の場合だけ。容量を大きくするなら、ファームウェアは VCM の時定数の約 5 倍（100 nF なら 25 ms、1 µF なら 250 ms）待ってから AFE_RST を下ろす。

## 電源投入：プロセスの角と電源の立ち上がりの速さ（11/15、図 37、`powerup_checks.py`）

ここまでの電源投入は、typical、モンテカルロ、AVDD ±5 % で、電源の立ち上がりは 1 ms だけだった。11/15 に、12 回目のチップの配線で `afe_startup.py` の power（AFE はリセットのまま、チョッパは止まったまま、AFE_IBIAS は code 2）を次の 20 本で回した。バイアス回路の起動回路の節点（SB、G1）も残した。1 本 30〜100 秒。

- プロセスの角 ss／ff／fs／sf と typical、それぞれ AVDD 3.135／3.3／3.465 V（立ち上がり 1 ms）。角は MOS に、合わせた抵抗、MIM、ダイオード、MOS 容量の角を付けたもの（fs は NMOS が速く PMOS が遅い）。
- 電源の立ち上がり 10 µs、10 ms、100 ms（typical、3.3 V）。100 ms は ss の 3.135 V と sf の 3.465 V でも。AVDD、DVDD、外の基準は同じ速さで上がる。

結果：

- **20 本ともバイアスが立ち上がった。** 立ち上がり 1 ms の 15 本で、AFE の VBN が最後の値の 1 % 以内に入るのは電源投入から 0.82〜1.05 ms（ss が遅く、ff が速い）。
- **起動回路は毎回切れる。** SB は弱い PMOS（W1/L50 の 2 本の直列）で持ち上がっていて、コアが流れ出して G1 が上がると落ちる。落ちるのは AVDD が 0.61〜1.03 V のときで（立ち上がり 10 µs だけは、追いつかずに 2.13 V）、そのあとの SB は 9〜15 mV（起動回路のスイッチは切れたまま）。
- AFE のテールの VBN（code 2）と AVDD の電流：

  | | typical | ss | ff | fs | sf | モンテカルロ 18 本（図 26 のラン、RESET_N の前） |
  |---|---|---|---|---|---|---|
  | VBN − AVSS（AFE） | 821.7 mV | 920.0 mV | 727.3 mV | 738.2 mV | 905.6 mV | 790.4〜845.8 mV |
  | AVDD の電流（ADC の 4.7 mA を含む） | 24.0 mA | 20.7 mA | 28.9 mA | 23.9 mA | 24.1 mA | 22.4〜25.4 mA |

  - AVDD ±5 % では、VBN は 1 mV 以内、電流は 0.2 mA 以内しか変わらない。
  - 角での AFE の電流の動き（ss −14 %、ff +20 %、AVDD の電流で）は、10/22 の回路図での見積もり（`gf180_afe_noise_20261022.md` の「バイアス回路とコーナー」）と同じ向き。角での雑音をチップの配線で回していないのは、管理表の「リスク」にある既知の項目のまま。
- **立ち上がりの終わりの VBN の小さな落ち込み（約 20 mV）は、AFE のテールが電流を流しきって AFE の AVSS が持ち上がるため。** 電源が上がりきると、AFE の AVSS はバイアス回路の AVSS より 24 mV 高くなる（typical）。バイアス回路の VBN は動かない。
- **電源の立ち上がりの速さによらず、同じ値に落ち着く。** VBN が 1 % 以内に入るのは、10 µs で 0.38 ms、1 ms で 0.93 ms、10 ms で 5.26 ms、100 ms で 47.5 ms（ss の 3.135 V で 52.8 ms、sf の 3.465 V で 51.9 ms）。最後の値は 1 ms のときと 0.01 mV 以内で同じ。VCM が 1 mV 以内に入るのは、電源が上がりきってから 1.2〜4.3 ms（10 nF。遅いのは ss の角）。
- リセット中の増幅器の出力（OPI − ONI）は、ゆっくり上がる電源の途中（AFE の電源が約 1 V のとき）で振れ（10 ms で 3.3 mV、100 ms で 51 mV）、電源が上がりきる前に消える。10 µs では上がりきった直後に 11.8 mV 振れ、40 µs で消える。どれも最後は 0。

基板とファームウェアへの要求（足したもの）：

- **解除の時刻は、電源が上がりきった時刻から数える。** いまのファームウェアの時刻（RESET_N 4.8 ms、AFE_RST 5 ms）は、電源が 1 ms で上がる前提。レギュレータがゆっくり上がる（ソフトスタートなど）なら、電源が上がりきってから、いまと同じく 4 ms 以上（VCM 10 nF のとき）待って AFE_RST を下ろす。
- **AVDD と外の基準を、DVDD より先に上げない。** アナログのパッド（AVDD ×3、AVSS ×3、電極、VCM、VREFP、VREFN）はどれも asig_5p0 で、その ESD ダイオードはパッドから DVDD のリングへ、DVSS からパッドへ向いている（PDK の `gf180mcu_fd_io__asig_5p0`）。AVDD や外の基準が DVDD より 0.5 V ほど先に上がると、このダイオードが順方向になって、AVDD が DVDD のリングとデジタルを給電する。ここの計算はどれも全部の電源を同時に上げていて、順序をずらした計算はしていない（ngspice-46 は順方向の接合の電荷に不具合 #870 がある）。

11/15 まで回していなかった 2 つの起動の場面（角での AFE の解除と、電極に DC オフセットがある最初の電源投入）は、11/16 に回した。下の 2 つの節。温度は 27 °C だけ（ユーザーの指定）。

## 角での AFE の解除と、AFE の線形性の窓（11/16、図 38、41）

12 回目のチップの配線で、`afe_startup.py` の start（電源投入、パッド、基板、ボンディングワイヤ、eeg_bias／eeg_ref／afe_top の抽出、RTL の順序。AFE_IBIAS はファームウェアが 3 を書く）をプロセスの角で回した。解除の 20 µs 後からフルスケール（0.943 mV pk）の 2 kHz の正弦波を入れ、7 ms まで。BOOST_TRIM は、リセット値の 4/4 のままのものと、AFE_IBIAS と同じ書き込みで変えたもの（`afe_trim_start.py`、11/16 に追加）。1 本 2.3〜3.4 時間。

**立ち上がりは、どの角でも問題ない。**
- どの角（AVDD 3.135、3.3、3.40 V、トリムの有無）でも AFE は動き出し、解除のあと 2 つ目の信号周期（0.31 ms）から振幅は最後の値になる。
- 利得は typical の −2.2〜+0.9 %（ss は −1.0 %。AFE_IBIAS 2 にすると −2.2 %）。出力のオフセットは −0.114〜−0.087 mV。

**フルスケールの HD3（2 kHz）は、角と AVDD で大きく変わる。** 要求は −111 dBc（帯域内。2 kHz の値は帯域内の静的な値より数 dB 悪く出る。typical で −113.0 dBc に対して、AFE の台の静的な値は −120.3 dBc）。

| 角 | AVDD 3.3 V、4/4 | 3.3 V、10/22 の表のトリム | 3.135 V、4/4 | 3.40 V、地図のトリム |
|---|---|---|---|---|
| typical | −113.0 dBc | （表も 4/4） | −94.0 dBc | 2/2：−116.8 dBc |
| ss | −97.6 dBc | 2/2：−105.9 dBc（AFE_IBIAS 2 では −103.8） | −59.6 dBc | 2/2：−111.2 dBc |
| ff | −115.1 dBc | 8/6 は回していない | −107.2 dBc | 8/2：−114.9 dBc |
| fs | −106.1 dBc | 2/6：−111.1 dBc | | 2/2：−117.8 dBc |
| sf | −96.8 dBc | 8/4：−96.2 dBc | | 8/2：−115.3 dBc |

- HD2 はどれも −114.9 dBc 以下（3.3 V では −126 dBc 以下、3.40 V では −132.8 dBc 以下）。悪くなるのは HD3（ss −5 % では HD5 も −75.6 dBc）。

**原因は、PMOS カスコードのブースト段が AVDD を基準にしていること。**
- ソース接地のブースト段は、入力対のドレインを AVDD − VSG（ブースト段）に置く。入力と出力のコモンモードは VCM で決まり、電源とは連動しない。そのため PMOS カスコードの余裕は、AFE の電源が下がった分だけ（1 対 1 で）減る。
- チップの上で AFE が受け取る電源（AVDD_AFEI − AVSS_AFEI）は、基板の AVDD 3.3 V のとき 3.196 V（typical。AVDD 側で 44 mV、AVSS 側で 60 mV 落ちる）。10/22 の角の表は回路図で、電源 3.3 V、AFE_IBIAS code 2 で作った。チップでは電源が約 0.1 V 低く、AFE_IBIAS は 3 なので、表のトリムでは合わない。
- ss の −5 % では、増幅器の出力（OPI）の上側が 1.82 V で頭打ちになっていた（typical 3.3 V では 1.87 V まで振れる）。

**余裕の地図と台（`gf180/tapeout/sim/afe/afe_margin_map.py`、11/16）。**
- 10/22 に角の表を作った台（`afe_bias_noise.py`：eeg_afe と実際の eeg_bias、チョッパの位相を 1 つ止める）に、AFE の電源と VCM をチップの値で入れる。出力をフルスケールの頂点（OPI − ONI = ±0.30 V）まで DC スイープで動かし、各トランジスタの VDS − VDSAT を出す。1 点 1〜3 秒。
- 同じ台で、`afe_distortion.py` と同じ止めた位相の正弦波（1 kHz、フルスケール、負荷は ADC の入力抵抗）から HD3 を出す。1 本 3〜5 分。
- 較正：チップの通し 21 本（3.135〜3.465 V）に対して、台の HD3（AFE の出力）は、ss の 2/2 を除いて 1.1〜9.1 dB 悪く出る。ss の 2/2 では台とチップがほぼ同じ（3.366〜3.45 V で差 0.5 dB 以内。3.3 V では台が 1.5 dB、AFE_IBIAS 2 では 4.7 dB 良い）。順位は合う（図 41 の左下）。
- 台では、出力チョッパの TG も HD3 を足している（AFE の出力と、TG の前の OPI − ONI の差）。ss ではその分だけで −107〜−111 dBc になる。

**AVDD に対する窓（台、AFE_IBIAS 3、図 41 の上）。**
- AVDD −5 %（3.135 V）では、typical、ss、sf、fs は、どのトリムでも要求に届かない（最良のトリムで typical −103.0、ss −88.9、sf −107.0、fs −87.2 dBc。typical の 4/4 は −88.8 dBc）。ff は 2/2 で −108.9 dBc（台はチップより悪く出るので、届く見込みはある）。
- AVDD を上げると、どの角も良くなる。3.38 V（+2.5 %）で最良のトリムにすると、typical −114.3（2/2）、ss −110.8（2/2）、ff −112.7（6/2）、sf −111.1（8/2）、fs −114.1 dBc（2/2）。チップの配線で落ちる約 0.1 V を、基板で補う形になる。
- 上げすぎると、ff で PMOS 入力対の余裕がなくなる（3.465 V では、試したトリムでいちばん良くても −104.1 dBc）。sf は 8/2 にすれば 3.465 V でも −112.9 dBc。
- いちばん良いトリムは、ほとんどが NMOS カスコード側を 2 単位（いちばん低い設定）にするもので、10/22 の表とは違う。

## 電極に DC オフセットがある最初の電源投入（11/16、図 39）

`afe_saturation.py`（11/16）：start のデッキで、DAC を切ったまま（範囲 0、BLANK 7 MCLK）5 ms に AFE_RST を下ろす。6.0012 ms（チョッパの半周期の中ほど）に、ホストが範囲と M を BLANK 15 MCLK と一緒に書く。電極のオフセットは 30 mV（範囲 1、M 100）と 300 mV（範囲 4、M 997）、typical、3.3 V。ADC は入力抵抗と仮想接地だけ（ADC 自身の過負荷と戻りは次の節、図 40）。

**飽和している間。**
- DAC が切のままだと、オフセットで増幅器が飽和する。ADC の入力の周期平均は 1.45 V（30 mV）と 1.83 V（300 mV）で、ADC の範囲（DAC1 のフルスケール ±0.484 V）の外。
- 入力（INP、INN）は帰還から外れ、電荷は DC 経路（約 72 MΩ）でしか抜けない。300 mV では入力のコモンモードが 1.27 V まで下がる（リセット中でも、DAC が切だと 0.36 V 低い）。

**書いたあとも、増幅器は出力チョッパの後ろで飽和したまま残る。**
- DAC を書くと、出力の周期平均は 0 付近に落ちる。ところが ADC の入力の瞬時値は、±1.2〜1.5 V の方形波のまま（チョッパの周期で符号が変わり、平均すると消える）。CIC の値だけを見ると、戻ったように見誤る。
- 戻す道は DC 経路だけで、30 mV では書いてから 0.82 ms で ADC の範囲に入る。300 mV では 2.82 ms かかる（電源投入から 8.82 ms。パルスなしで 11 ms まで回したランで、11/17 の 2 時 30 分に終わった。8 ms までは 8 ms のランと 0.65 µV 以内で同じ）。
  - 飽和した出力が DC 経路に一定の電流を流すので、INP − INN（周期平均）は書いたあとの −58 mV から 24 mV/ms の直線で戻り、8.44 ms ごろに 0 に届く（図 39 の (c)）。
  - 範囲に入ったあとも、入力のコモンモードは図 27 より 0.18 V 低いまま（11 ms で 1.449 V、図 27 は 8 ms で 1.632 V）。9〜11 ms の当てはめでは、時定数約 47 ms でしか戻らない。
  - 出力（周期平均）は、11 ms でも図 27 の落ち着いた値（8 ms で −44.15 mV）より −9.25 mV（入力換算約 −31 µV）ずれていて、0.23 mV/ms で近づいている。入力のコモンモードの不足に 46 mV/V（下のパルスのランで出した比）を掛けると −8.4 mV で、ずれはほぼこれで説明できる。
  - パルスなしでも 300 mV の AFE は自分で戻る。ただし ADC の範囲の外に 2.8 ms いて、そのあと入力換算約 −31 µV のずれが、入力のコモンモードと一緒に時定数約 47 ms で抜けていく。100 µs のパルスなら 0.5 µs で範囲に入り、2.5 ms 後のずれは +0.20 mV（入力換算 +0.7 µV）。手順（書くたびに 100 µs）はこのままでよい。

**書いたあとに AFE_RST をもう一度上げると戻る（`--rst-pulse`）。** 書いてから 20 µs 以上あけて AFE_RST（CONTROL[4]）を上げ、最初の解除と同じチョッパの位相で下ろす。パルスは 20 µs（30 mV、300 mV）と 100 µs（300 mV、11/16 の 11 時 7 分に終わった）。
- どのパルスでも、ADC の入力は AFE_RST を上げてから 0.2〜0.5 µs で範囲に入る（書いてから 0.024〜0.026 ms）。パルスの間は ±54 mV 以内。
- リセット中、入力のコモンモードは 1.664 V に向かって時定数 11 µs で戻る（300 mV、図 39 の左下）。20 µs では最後の半周期で 1.613 V で、51 mV 足りない。100 µs なら約 60 µs で 1 mV 以内に入る。
- 解除のあと、入力のコモンモードは DC 経路でしか動かない。1.5 ms 後に、20 µs では 1.597 V、100 µs では 1.637 V（図 27 は 1.631 V）。
- 出力は入力のコモンモードに、DAC の電荷を通して M に比例して付いてくる（AFE の出力で、M 997 では 46 mV/V、M 100 では 5 mV/V）。図 27 と比べた出力は、300 mV の 20 µs で −1.59 mV（1.5 ms、まだ離れていく）、100 µs で +0.28 mV（1.5 ms）と +0.20 mV（2.5 ms、近づいていく）。30 mV の 20 µs は −0.04 mV（図 39 の右下）。
- VCM_AFE（基板の 10 nF）も動く。飽和の間は AFE に引かれて 1.616〜1.645 V、書いたときに 1.665 V、パルスの中で 1.689 V まで上がり、解除のあと時定数約 0.55 ms で戻る（2.5 ms 後に 1.651 V。図 27 は 1.649〜1.651 V）。100 µs のあとの出力の動き（0.25〜2.5 ms で約 0.7 mV）は、入力のコモンモードがこれに引かれて動く分（17 mV × 46 mV/V）。
- 決め：ホストは DAC を書くたびに AFE_RST を 100 µs 上げる（`gf180_electrode_dc_20261022.md` の「使い方」、11/16 に直した）。
- **ss でも戻る（300 mV、M 997、100 µs、11/16 の 14 時 38 分に終わった）。**
  - リセット中の入力のコモンモードは、時定数 14 µs で 1.626 V まで上がり、パルスの中で届く（typical は 11 µs で 1.664 V）。

## ADC の過負荷からの戻り（11/16、図 40、`adc_overload.py`、`adc_overload_beh.py`）

AFE が飽和している間、ADC の入力は ±1.2〜1.5 V の方形波（前の節）で、ADC の範囲（DAC1 のフルスケール ±0.484 V）の外にある。AFE が戻ったあと、ADC が自分で戻るかを確かめた。

**抽出したループ（`adc_overload.py`）。** 抽出した eeg_adc、eeg_bias、eeg_ref、チップの基準の配線、RTL のフレーム、DWA。typical、27 °C、ADC の AVDD 3.245 V。入力は ADC のピンでの差動。
- +2.5 V を 50 µs → フルスケールの 20 kHz の正弦波（0.28 V pk）を 60 µs → −2.5 V を 50 µs → また正弦波。
  - 2 つの積分器はどちらもレール（O1 ±2.27 V、O2 ±3.25 V）に張りつき、OTA は仮想接地を失う。OTA2 の仮想接地は、過負荷が終わってから 36 µs で 50 mV 以内に戻る。
  - それでも 60 µs の正弦波の間に、ループは戻らない（O2 は −1.6 V まで振れる）。
- +2.5 V を 150 µs → −39 mV の DC を 300 µs。−39 mV は、電極のオフセット 30 mV で DAC を書いたあとに、AFE の出力が落ち着く値。
  - 過負荷が終わってから 64 µs で戻る（O2 が量子化器の範囲 ±46.9 mV、O1 が ±0.2 V の内にとどまる）。仮想接地は、OTA1 が 10 µs、OTA2 が 28 µs で 50 mV 以内に戻る。
  - 79 µs からは符号 16 と 17 だけになる。平均は 16.78 で、−39 mV なら 16.75（差の 0.03 符号は、ADC の入力で約 1 mV）。

**行動モデル（`adc_overload_beh.py`）。** `adc_beh_mc.py` の 1 クロックごとのループ（両方の DAC の DWA、ループの遅れ 0.22 クロック）を、与えた状態から回す。積分器の出力は、抽出したランのレールで切る。OTA が仮想接地を失ってから戻るまで（OTA2 で 28〜36 µs）は入っていない。
- 確かめ：抽出した 2 方向のランで、OTA2 の仮想接地が戻ったところ（96.7 µs）の O1、O2 から回した。符号は 23 クロックすべてで抽出と同じ（2 µs あとからでは 21 クロックすべて）。
- 同じ状態から 2 ms 回した。
  - 20 kHz のフルスケールの正弦波を続けると、2 ms たっても戻らない（1 ビットのモード：O2 が 2〜3 V で量子化器の範囲を大きく外れたまま）。
  - DC（−300、−39、0、+300 mV）と 2 kHz の 0.28 V なら 21〜86 µs で戻る。
- 過負荷が終わったときの状態をばらまいた（O1 を ±2.27 V、O2 を ±3.25 V に一様、入力の位相も乱数で 300 通り）。ダイは typical、ブロックの角、R と MIM の角、ブロックのモンテカルロの 30 ダイの計 42。
  - 帯域内と 2 kHz まで（DC、32 Hz、2 kHz、0.1〜0.42 V pk）は、どのダイのどの状態も戻った。
  - いちばん遅い戻りは、0.28 V までで 186 µs、0.42 V で 402 µs（どちらも MOS ss・R ss・MIM ss）。typical では 143〜147 µs と 210〜305 µs。
  - 1 ビットのモードに残るのは、大きな 10〜20 kHz の入力だけ。20 kHz 0.28 V では 42 ダイすべてで、状態の 68 %（中央値）〜74 %。10 kHz 0.28 V では 2 ダイで、最悪 66 %。20 kHz 0.1 V では残らない（いちばん遅い戻りは 702 µs）。
  - 0 から始めたランは、どの入力でもこのモードに入らない。

**まとめ。**
- AFE が戻れば（AFE_RST を上げてから 0.5 µs で ADC の入力は範囲に入る、前の節）、ADC は自分で戻る。ADC を別にリセットする仕組みは要らない。
- 戻るまでの時間は、抽出したループで 30 mV の場面が 64 µs。ダイと状態のばらつきを入れると、0.28 V までの入力で最大 186 µs、OTA2 の戻り（約 36 µs）を足して約 0.22 ms。ホストは AFE_RST を下ろしてから、この分を待って FILTER_CLEAR を出す（`gf180_electrode_dc_20261022.md` の「使い方」、11/16）。ADC の入力はパルスの初めに範囲に入るので、戻りは 100 µs のパルスの間に始まっている。下ろしてから数える 0.22 ms は余裕を見た値。
- 1 ビットのモードは、過負荷のあとに ADC の入力で 0.1 V を大きく超える 10〜20 kHz が続くときだけ（電極では約 0.3 mV、AFE の利得 300 のとき）。電極にこの大きさの 10〜20 kHz の妨害が続く使い方では、過負荷のあとに戻らないことがある（妨害が下がれば戻る）。

## 電源、基準、バイアスの定常の動き（発振していないか）

図 26 の typical をシミュレータの計算点をすべて残して回し直し、解除後の 0.1〜0.4 ms（37 周期）で、電源、基準、バイアスの 20 節点を調べた（各節点の差を、チョッパ周期ごとに切って重ね、周期ごとに同じ部分と違う部分に分けた）。発振している節点はない。

- チョッパの切り替えのたびに 10〜50 ns の過渡がある（p-p：AFE のクロックドライバの電源 0.59 V、VCM − AVSS 144 mV、AFE の電源 108 mV、BLP 106 mV、VBCM 88 mV、バイアス回路の電源 53 mV、β マルチプライヤのゲート 51 mV、ADC の電源 45 mV、VBN 12 mV、VREFP − VREFN 1.6 mV）。どれも毎周期まったく同じ形で、一度逆向きに行き過ぎてから時定数約 0.5 µs（基板のレギュレータの出力抵抗 50 mΩ × 10 µF）で戻る。毎周期同じなので出力では一定のオフセットになるだけで、その分はシミュレーションした出力（上の −0.075 mV）に入っている。
- 切り替えから 1 µs 以降の静かな区間で、周期ごとの違いは、電源、VBN、BLN、GP、ADC の OTA のバイアス、DVDD で 10 nV 以下、VREF、BLP、クロックドライバの電源で 30 nV 以下。シミュレータの計算の誤差の大きさ。
- 基板のグラウンドから見た節点（パッド、AVSS、VCM）は、計算点ごとに約 ±0.7 µV 交互に振れる。台形積分がボンディングワイヤのインダクタンス（2 nH、20 Ω で減衰）で起こす数値上の振動で、チップ全体で同じなので、回路が使う差では消える。
- このシミュレーションに雑音源はなく、レギュレータは理想の電圧源（出力抵抗だけ）。実際のレギュレータの雑音が出力にどれだけ出るか（PSRR）は、11/19 にリップルを乗せたランで確かめた（下の「電源の除去（PSRR）とレギュレータへの要求」、図 46）。

## フルスケールの正弦波での ENOB（11/14、図 35、`enob_sine.py`）

これまでの「16.44 bit」などは、電極換算の雑音の二乗和 N を 16.5 − log2(N / 5.88 nVrms) で bit に直した値（図 07）。ADC 側の 2.93 nVrms は 10/22 の予算の配分のままだった。ここでは ENOB を本来の定義で出した。電極にフルスケールの正弦波を入れ、DATA の FFT から 0.5〜100 Hz の SINAD を求め、ENOB = (SINAD − 1.76) / 6.02 とする。

- **トランジスタのままでは回せない。** 帯域の下限が 0.5 Hz なので、記録は秒単位でいる。チップの通し（電源投入から CIC の出力まで）は、10 ms に約 2.5 日かかる。
- **抽出したブロックの結果をつないだ鎖で回した**（`gf180/tapeout/pex/enob_sine.py`、結果は `runs/enob_sine_r12/`）。
  - 入力：電極に 0.943 mV pk、10.13 Hz。DATA 8192 点に 83 周期で、2〜9 次の高調波が帯域に入る。信号源の熱雑音は、目標の定義どおり入れない。
  - AFE：12 回目の抽出の静的な伝達を、通しの傾き 297.75 で使った。`afe_dcpath.py static` の ±0.943 mV までの 8 点を 5 次で当てはめたもので、フルスケールで HD3 −120.4 dBc。
  - AFE の雑音：チップの上のモンテカルロ（12 回目の配線、AFE_IBIAS 3）の値を、ダイごとに白色雑音として入力に足した。出力チョッパのブランキングの折り返し 0.681 nVrms も足した。
  - ADC：行動モデルのループ（`adc_beh_mc.py`）を、抽出した ADC のブロックのモンテカルロのダイで、ELD 0.22 で回した。ダイは 11 回目のもので、12 回目とブロックは同じ。
  - ADC の雑音：熱雑音（抵抗 1.17、OTA1 0.27、OTA1 のチョッパの折り返し 0.17 nVrms）を入力に足した。ポリ抵抗の 1/f は、`adc_flicker.py` のモデル B の大きさの利得のゆらぎとして入れた。
  - デジタル：eeg_cic3 をビット一致で入れた（実行のたびに `cic_golden.py` と照合）。DATA は 1 kS/s で、FFT は矩形窓。
  - ADC のダイ k には、AFE のモンテカルロの種 k を組み合わせた（別々の抽選）。角は AFE を typical にした。

| | ENOB (bit) | 垂れを補正 (bit) | SINAD (dB) | 雑音と歪み (nVrms) |
|---|---|---|---|---|
| typical（9 本の記録の平均） | 16.61 | 16.59 | 101.75 | 5.45 |
| モンテカルロ 30 ダイ | 16.54〜16.69（平均 16.60） | 16.52〜16.66 | 101.34〜102.21 | 5.17〜5.72 |
| ブロックの角 10 | 16.54〜16.63（平均 16.59） | 16.52〜16.60 | 101.34〜101.86 | 5.38〜5.72 |
| typical、雑音なし（AFE の伝達とループ） | 19.37 | | 118.36 | 0.81 |
| 同、AFE を線形に（ADC だけ） | 20.05 | | 122.46 | 0.50 |

- **「垂れを補正」は、CIC の sinc³ の垂れ（100 Hz で −0.43 dB）を周波数ごとに戻した値。** 予算の 0.5〜100 Hz は平らな帯域としているので、予算と比べるならこちら。
  - sinc³ は帯域内の白色雑音を約 3 % 減らす。入力なしの DATA の雑音は 5.42 nVrms で、入れた 5.51 nVrms の 0.985 倍。
- **1 本の記録（8.19 秒、815 bin）の雑音の推定は、ENOB で約 0.03 bit（1σ）ばらつく。** typical の 9 本で 0.031 bit。
  - ダイの間の差（30 ダイで σ 0.037 bit）の大半はこれで、ダイそのものの差は σ 約 0.02 bit。
  - 最悪のダイの値も、この推定のばらつきを含んでいる。
- **予算の 16.44 bit より上に出たのは、ADC 側が配分の 2.93 nVrms より小さいため。** 正弦波の試験での ADC 側は約 1.37 nVrms：熱雑音 1.21、ループの量子化・DAC・歪み 0.50、ポリ抵抗の 1/f 約 0.37（この記録の長さで、正弦波のすぐ脇の bin まで数えた値。`adc_flicker.py` は ±0.5 Hz を正弦波に数えて 0.29）。
  - 雑音なしの SINAD 118.4 dB（0.81 nVrms）は、AFE の HD3（−120.4 dBc）と、DAC1 の偶成分による HD2（−122.7 dBc）で決まる。
  - 11/12 に測った値で積み直した 5.60 nVrms、16.57 bit（外付けの基準の要求 0.5 nVrms を含む）とも合う。基準の分を除くと 16.58 bit で、垂れを補正した 16.59 bit と 0.01 bit 違うだけ。
- **振幅を振ると、SINAD はフルスケールまで傾き 1 で伸びる。** 雑音で決まっていて、歪みで曲がらない。ダイナミックレンジ（フルスケールの SNR）は 101.9 dB。
- **入っていないもの**：
  - ADC の歪みのうち行動モデルにないもの。11/14 の時点では、トランジスタのループの計算（8 ms）で −110 dBc より下が見えていなかった。−110 dBc の歪みがあれば −0.10 bit（垂れを補正した値で 16.49 bit）、−120 dBc なら −0.01 bit。
    - **11/15 に OTA の分を測った**（下の節、図 36）。帯域内の誤差は −150 dBc より小さく、ループに入れても ENOB は 0.5 mbit も変わらない。
    - 残るのはポリ抵抗の電圧係数。PDK のモデルには項があるが、値は 0。11/17 に許容を見た：HD3 が −111 dBc に届くのは vc2 が約 370 ppm/V²、16.5 bit を保つのは約 300 ppm/V² まで（図 43、下の「PDK にない係数への余裕」）。
  - 外付けの基準電圧。要求の 0.5 nVrms（フルスケール）を足すと −0.006 bit。
  - クロックのジッタ。11/15 に DAC1 の切り替えのエッジの分を出した（下の節）。
- **実機で同じ試験をするときは、信号源の抵抗の熱雑音がそのまま入る。**
  - 片側 100 Ω なら、0.5〜100 Hz で 18.2 nVrms になり、ENOB は約 14.8 bit。
  - チップの 16.5 bit を見るには、出力インピーダンスが片側 1 Ω 程度（1.8 nVrms、−0.07 bit）で、歪みが −120 dBc より小さい信号源がいる（低歪みの発振器と抵抗の分圧など）。
- **フルスケールは予算の 0.943 mV pk。**
  - ADC の入力では 0.281 V pk で、DAC1 のフルスケール 0.48 V の約 58 %。変調器は行動モデルで 0.44 V pk（電極 1.48 mV）まで線形。
  - 雑音で決まったまま 1.48 mV まで伸びれば +0.65 bit になる。ただし AFE の伝達は ±0.943 mV までしか測っていないので、この値は出していない。

## ADC の OTA の非線形と DAC1 のジッタ（11/15、図 36、`ota_static.py`、`ota_distortion.py`）

11/14 の ENOB の試験は、ADC の行動モデルの OTA を線形（DC の利得だけ）としていた。最悪のダイが 16.5 bit を割らずに足せる誤差は、−113.7 dBc（電極換算 1.38 nVrms）しかない。トランジスタで歪みを見たのは 10/22 の回路図のループ（1 kHz、8 ms）だけで、−110 dBc より下は量子化雑音の床で見えていなかった。そこで、抽出した OTA の静的な伝達を測り、行動モデルの積分器の出力に当てた。

- **測り方**（`gf180/tapeout/pex/ota_static.py`、結果は `runs/ota_static_r12/`）：
  - ブロックのモンテカルロの OTA のベンチ（`adc_block_mc.py` の ota）を使った。抽出した OTA、抽出した eeg_bias と eeg_ref、段の負荷が入っている。
    - OTA1 の負荷は RIN、DAC1 の抵抗、C1、R21、出力の配線。
    - OTA2 の負荷は R21、C2、量子化器、出力の配線。
  - 積分コンデンサにかけた 1e16 H の直流の帰還に、片側 ∓VD/2 の電圧源を直列に入れた。直流では出力の差が VD になり、そのとき OTA が要る入力の差（仮想接地の電圧）が出る。
  - VD は OTA1 で ±0.6 V、OTA2 で ±0.3 V まで振った。gmin は 1e-15。
  - OTA1 はチョッパを相 A と相 B に止めて、両方回した。typical、ブロックの角 4 つ（ss、ff、fs、sf）、モンテカルロ 1〜10。OTA2 は typical と角。
  - OTA と負荷は r11 と r12 で同じなので、r11 のブロックのベンチ（`runs/adc_mc_r11/nets`）をそのまま使った。OTA のセルは r6 と XOR で同じ。
- **静的な伝達**（typical）：
  - OTA1 の利得は 70.2 dB（角で 70.0〜70.3 dB）で、出力に対してほとんど変わらない。
  - 仮想接地の電圧から、オフセットと利得の分を除いた残り（非線形の分）は、typical と角ではほぼ 3 次。出力 ±0.1 V で ±0.74 nV、±0.2 V で ±5.4 nV（角で ±0.1 V のとき 0.38〜1.68 nV）。線形の分は ±0.1 V で 31 µV。
  - モンテカルロのダイでは、ずれで偶数次（2 次）が出る。出力 ±0.1 V で最大 −14〜−15 nV（mc10、両相とも同じ向き）。オフセットは両相で符号が逆の ±3〜131 µV で、チョッパで帯域の外へ移る。
  - 出力が ±0.4 V を超えると曲がり始める（出力の同相が下がる）。
  - OTA2 は 104.5 dB で、非線形の分は出力 ±0.1 V で ±0.37 nV。
- **フルスケールでの積分器の振れ**（行動モデル、雑音なし）：O1 は ±88 mV（typical。どのダイでも ±96 mV 以内）、O2 は ±32 mV（±39 mV 以内）。
  - O1 の振れの大半は、信号の写し（入力の約 0.3 倍）。2 段目では R21 の電流が DAC2 の電流（信号を追う）とつり合うので、1 段目の出力に信号の (R21/RD2)·VREF/vfs ≈ 0.3 倍が出る。量子化のリップルは数 mV。
  - OTA1 が曲がり始める ±0.4 V より十分小さい。
- **ADC の入力での誤差**（`gf180/tapeout/pex/ota_distortion.py`）：
  - OTA1 の仮想接地の誤差は、RIN と、振り分けた DAC1 の抵抗の両方の電流を変える。ADC の入力では 1 + RIN/RD1 = 1.97 倍で、ループはこれを信号と同じに DATA へ通す。
  - OTA2 の誤差は R21 を通って 1 段目の出力に入る。入力に換算すると RIN C1 × 微分で、帯域ではさらに小さい。
  - 誤差は信号よりずっと小さく、ループの応答は線形とみなせる。そこで、雑音なしのループの積分器の出力に曲線を当てて誤差の列を作った。1 クロックの中の平均をとり、eeg_cic3 の sinc³ / 1024 を浮動小数点で通し、1 kS/s の FFT から帯域のぶんを出した。
  - 方法の確かめ：typical の OTA1 の曲線を 1.27 万倍して、この計算で HD3 が −100.00 dBc になるようにし、ループに入れた（雑音なし、AFE は線形）。DATA の HD3 は −100.04 dBc（入れないと −174 dBc）で、0.04 dB で合った。
- **結果**（フルスケール、DATA 2048 点、11.23 Hz）：

| | 帯域内の誤差（dBc、正弦波の bin を除く全部） | 電極換算 |
|---|---|---|
| OTA1 | −150（mc10）〜 −188（ss の角）。typical −182、角 −175〜−188、モンテカルロ 1〜10 は −150〜−184 | 0.27〜21 pVrms |
| OTA2 | −275 以下 | — |
| 最悪のダイが 16.5 bit を割らない誤差 | −113.7 | 1.38 nVrms |

  - typical と角ではほぼ HD3、モンテカルロのダイでは偶数次による HD2 が大きい（mc10 で −149.9 dBc、mc5 −157.6、mc8 −158.1）。どれも最悪のダイの余裕より 36 dB 以上小さい。
  - O1 の振れの位置で OTA1 に許される非線形の分は、3 次なら 1.2 µV、2 次なら 0.6 µV（最悪のダイの余裕を使い切る大きさ）。実際は 0.3〜11 nV（mc10 の 2 次が最大）。
- **ループに入れた ENOB**（`enob_sine.py --ota-nl`、`runs/enob_sine_r12/enob_sine_otanl.json`）：
  - 図 35 と同じ 61 列、同じ雑音の抽選で、OTA1 と OTA2 の曲線をループに入れた。ベンチのないダイ（モンテカルロ 11〜30、抵抗と MIM の角）は typical の曲線。
  - ENOB の変化は、雑音と正弦波のある 58 列のどれも ±0.45 mbit 以内（typical の 9 本で平均 +0.03 mbit、モンテカルロ 30 で +0.03、角で −0.01）。雑音なしの 2 列は SINAD で 0.004 dB 以内。ループの符号の列は分かれるので、量子化雑音は別の抽選になるが、その差もこの大きさ。
  - 結果は図 35 と同じ：typical 16.61 bit、モンテカルロ 16.54〜16.69 bit、角 16.54〜16.63 bit（垂れを補正して最悪 16.52 bit）。雑音なしの SINAD は 118.361 dB（図 35 は 118.362 dB）。
- **DAC1 の切り替えのジッタ**（同じ計算から）：
  - NRZ の DAC1 は、更新のエッジが δt ずれると、そのクロックで vfs × (y[n] − y[n−1]) × δt / T の誤差になる。白色のジッタなら誤差も白色。DAC2 の分は 1 段目で整形される。
  - フルスケールで、符号の変化は 1 クロックあたり 0.7〜1.5 符号（rms）。電極換算で 10 ps rms あたり 0.010〜0.023 nVrms。0.5 nVrms になるのは 220 ps rms。
  - DAC_CLK は MCLK（基板の発振器）から RTL のフレームで作るので、数十 ps までならまず効かない。チップの中のクロック経路のジッタは見積もっていない。
- **ポリ抵抗の電圧係数**：
  - PDK の ppolyf_u には電圧係数の項がある（r_vc1、r_vc2、1 square あたりの電圧で効く形）が、値は 0。
  - RIN は 1 本 400 square で、フルスケールでも 1 square あたり 0.2 mV しかかからない。この形の係数なら、値があっても効かない。
  - DAC1 の抵抗は両端の電圧が変わらない（ステアリング型）。
  - モデルの形にない、基板との電位差による変化は、差動で奇数次が打ち消し合う。偶数次は P と N の係数の差だけが残る（HD2 ≈ 差 × ADC の入力の差動振幅 / 16。フルスケールの 0.281 V で −120 dBc になるのは、差が 57 ppm/V のとき）。実機でしか確かめられない。

## 図の平均の取り方（10/29 に直した）

図 26、27 の解除後の整定に 62.5 µs おきの揺れが出ていたのは、図の計算の作り物だった。結果のファイルは 100 ns 刻みで、チョッパの 1 周期 7.8125 µs は 78.125 刻みなので、刻みと切り替えの瞬間の位置関係は 8 周期（62.5 µs）で一巡する。チョッパ周期の平均の区切りをちょうど切り替えの瞬間に置くと、鋭い過渡を位置関係ごとに違う量だけ拾う（0 V で 1.4 µV p-p、30 mV で 244 µV p-p）。区切りを切り替えから 1/4 周期ずらすと 0.02 µV p-p に下がる。図 26 の下段（VBN と AVDD の電流）は、計算点をすべて残して回し直した結果から描いた。

## 電源投入から CIC の出力までの通し（10/28〜、`e2e_startup.py`）

電源投入から 10 ms まで、AFE と ADC を抽出したトランジスタで（チップの配線、パッド、基板、ボンディングワイヤ込み）回し、ADC のコードを RTL の CIC（`eeg_cic3`）に通した。typical、電極は 0.3 mV の DC に 16 kHz・0.5 mV の正弦（CIC の零）、VCM の容量 10 nF。AFE_RST の解除は 5 ms で、CIC のクリアは同じフレーム。54 チャンクのチェーンで、r6 は 11/1 15 時、r7（ADC の C1・C2 を 1.25 倍）は 11/2 5 時、r9（9 回目のチップの配線）は 11/11 0 時 26 分に最後まで回った。図は診断用で、図のセットには入れていない（`gf180/tapeout/pex/runs/e2e_startup/e2e_chain_r6_r7_20261107.png`、`e2e_chain_r7_r9_20261111.png`）。

## デジタル側：9 個のパッドとデジタルブロックの電源電流（11/8〜、`digital_noise.py`）

- **9 個の bi_24t：**
  - PDK のトランジスタのネットリストをリングに置いた。端子のつなぎ方は `chip_lay.DPAD` のとおり。

| AFE の入力の差動 | | b1 − b1iso：7.5 µV p-p（CHOP のエッジの直後 50 ns を除く） | b3 − b1：16.7 µV p-p（同じく除く） |

CHOP のエッジの直後 50 ns では、差動の差が最大 ±10 µV になる。ただし符号はエッジごとにばらばらで、2 本の計算の点が切り替わりの過渡の上でずれた分である。

AFE の出力のチョッパ周期ごとの平均を、5 周期で比べた。差は、一定のずれと、入力の 16 kHz の正弦（出力で 148.9 mV）の成分に分けた。正弦の周期ごとの平均は計算で正確に出せるので、それを基底にして当てはめた。

| 組 | 一定のずれ（電極換算） | 16 kHz の成分 | 残り | ADC の符号 |
|---|---|---|---|---|
| b1iso − 元のチャンク（計算の差） | +0.13 nV | 1.8 ppm | 0.04 nV rms | 48 フレームとも一致 |
| b1 − b1iso（結合） | +0.21 nV | 0.8 ppm | 0.08 nV rms | 48 フレームとも一致 |
| b2 − b1（SPI の読み出し） | −0.06 nV | 0.4 ppm | 0.17 nV rms | 48 フレームとも一致 |
| b3 − b1（RAW の出力） | −0.11 nV | 0.4 ppm | 0.11 nV rms | 48 フレームとも一致 |

b2 − b1 と b3 − b1 には、足した事象（SPI、RAW の出力）による計算の差も入っている。

- **結合の大きさ：** デジタル側の結合で AFE の出力にできる一定のずれは、電極換算で 0.21 nV。DATA の 1 LSB（0.19 nV）とほぼ同じで、シミュレータ自身の計算の差（0.13 nV）と同じ大きさ。周期ごとの差の大部分（最大 1.0 nV）は、16 kHz の正弦に対する ppm 単位の計算の差だった。
- **一定のずれにしかならない理由：** b1 では、チョッパ（MCLK／256）、フレーム（MCLK／32）、デジタルの電流がどれも MCLK に同期している。そのため結合は雑音にならない。0.2 nV は、雑音（総残差 6.3 nVrms、0.5〜100 Hz）や電極の DC オフセットと比べて無視できる。
- **SPI の読み出し：** ホストの SPI のクロックは MCLK と同期していないので、読み出しのたびにずれ方が変わる。それでも周期ごとの残りは 0.17 nV rms で、読み出し（26 µs）はサンプル周期（1 ms）の 2.6 % なので、無視できる。
- **小さなデッキでの切り分け（診断）：** 別に、リング、基板、デジタル側と簡単な負荷だけの小さなデッキを回した。電極のパッドの同相の揺れ（2.3 mV p-p）は MCLK のパッドのエッジから、リングとブロックの電源の揺れはコアの電流から来ていた。電流の三角形の幅を 1〜4 ns に変えると、リングの揺れは 71〜35 mV p-p になる。
- **b3（RAW の出力）：**
  - 最初の回しは 12.57 µs で「Timestep too small」で止まった（時間刻み 1.25e-17 s）。
  - 原因は区切り点の近さだった。RAW_CLK（PULSE）と RAW_DATA（PWL、時刻を 10 fs 刻みで書いた）の角が、チップのクロック（CMP、DCK、CHOP、BLK）と同じ格子に乗っていた。そのため、3 fs だけ離れた区切り点ができていた。
  - 2 本を同じ式から作った PWL にし、格子から 0.125 ns ずらした（コアの出力がパッドの A に着く時刻の違いとして、ありうる範囲）。デッキの近すぎる区切り点は、b1 と同じ浮動小数点の 1 ULP の差だけになった。これで 11/9 6 時 55 分に回し直し、21 時 4 分に 47.3 µs の最後まで回った（14.1 時間）。
  - 11/11 の訂正：このとき「b2 も 1 ULP の差だけ」としたのは誤りだった。b2 では MISO の角も格子の上にあり、ストローブの角と 3 fs だけ離れた組が 4 つあった。7 回目の抽出の b2 はそこを通ったが、10 回目の抽出の b2 はそこで止まった（下の「10 回目の抽出での回し直し」）。
  - RAW の出力で、リングの DVDD の揺れは 59 → 65 mV p-p になった。AFE の入力には RAW_CLK のエッジ（61 ns ごと）で鋭い揺れが足され、b3 − b1 は同相 15.2 mV p-p、差動 16.7 µV p-p（CHOP のエッジの直後を除く）。b1 の結合（7.2 mV、7.5 µV）の約 2 倍。
  - それでも AFE の出力では、一定のずれ −0.11 nV、周期ごとの残り 0.11 nV rms で、SPI の読み出し（0.17 nV rms）と同じ大きさ。ADC の符号は 48 フレームとも一致した。
  - RAW_CLK は MCLK を 4 で割ったものなので、周期ごとに変わるのは RAW_DATA の切り替わり（ここではランダム）だけ。残りの 0.11 nV rms（計算の差も含む）が周期ごとにばらばらの雑音だとしても、0.5〜100 Hz に入るのは約 0.005 nV rms で、総残差 6.3 nVrms と比べて無視できる。
  - 実際の RAW_DATA は変換の結果なので、入力によって変わる。ここでの差は全部で 0.2 nV 以下なので、入力によって変わる分もそれ以下。RAW の出力は試験用で、普段の測定では止まっている（RAW_EN = 0）。
  - 最初の回しで止まる前の 1 周期は −0.31 nV（RAW の角が格子の上）、回し直しの同じ周期は −0.01 nV。この差は、シミュレータ自身の周期ごとの差（b1iso − 元のチャンク、−0.6〜+1.0 nV）の範囲に入る。

**10 回目の抽出での回し直し（11/10〜11/11）：** ADC を 10 回目の抽出（`runs/adc_top_c_r10`）に差し替えて、5 本を回し直した（`digital_noise.py --adc r10`、結果は `runs/digital_noise_r10/`、比べた値は同じフォルダの `compare.json`）。

## PDK にない係数への余裕（11/17、図 43、`enob_sine.py --margin`、`margin_fig.py`）

PDK に値がないものは、これまで仮の係数（ポリ抵抗と MIM の素子ごとのばらつき）か、0（ポリ抵抗の電圧係数）で計算してきた。どこまで大きくなったら要求を割るかを見た。DAC1 と入力抵抗は、図 35 の正弦波の試験で回した（フルスケールを電極から、AFE の伝達、抽出した ADC のループのモデル、RTL のデシメータを通して DATA へ。0.5〜100 Hz の SINAD）。

**DAC1 の素子のばらつき（`--margin mm`、`mmlow`）。** ブロックの Monte Carlo（ポリ抵抗の仮の係数 3 %·µm）から来る DAC1 の素子の誤差（静的な誤差と、偶成分の電荷の素子ごとの部分）を 1、2、4、8 倍にした。DAC2、しきい値、そのほかはそのまま。
- 雑音込みの 30 ダイの ENOB は、平均 16.600、16.594、16.601、16.601 bit（最悪 16.515、16.525、16.552、16.557 bit）で、1 本の記録の揺れ（約 0.025 bit）の中で変わらない。DWA がばらつきを 1 次で整形し、オーバーサンプリング比が 5,120 あるので、帯域にほとんど残らない。
- 雑音なしの 6 ダイで、DWA のアイドルトーンが出やすい小さい入力も見た。帯域内の誤差はばらつきに比例して増える。最悪のダイで、−60 dBFS では 0.044、0.077、0.148、0.296 nVrms、入力なしでは 0.21、0.41、0.81、1.51 nVrms（×1、×2、×4、×8）。
- 8 倍の 1.51 nVrms でも、総残差 6.14 nVrms に二乗和で 3 %（約 0.04 bit）。実際には雑音が DWA の並びを崩すので、雑音なしのこの値は大きめに出る。

**入力抵抗の電圧係数（`--margin vc`）。** 入力抵抗を R(v) = RIN (1 + vc1 v + vc2 v²) にした（v は 1 本にかかる電圧）。DAC1 の抵抗は 2 つの値の間で切り替わるだけなので、電圧係数は値を少し変えるだけで、歪みにはならない。
- 雑音なしの HD3 は、vc2 が 0 で −120.4 dBc（AFE そのもの）、100 で −116.8、300 で −112.3、1,000 で −104.6、3,000 で −96.1、10,000 ppm/V² で −86.0 dBc。入力抵抗だけの見込み vc2 × (0.14 V)² / 4 とよく合う（フルスケールで 1 本にかかるのは ±0.14 V）。
- 要求の −111 dBc に届くのは vc2 が約 370 ppm/V²。雑音込みの ENOB は 300 ppm/V² で 16.52 bit、1,000 で 16.31 bit で、16.5 bit を保つのは約 300 ppm/V² まで。
- vc1 は差動の対で打ち消され、−vc1² として vc2 から引かれるだけ（10,000 ppm/V でも HD3 は −126.6 dBc で、むしろ下がる）。
- 入力抵抗は 1 本 18.75 kΩ で、300 kΩ の単位 16 本の並列。1 単位は 320.48 × 0.8 µm の ppolyf_u 2 本の直列（長さ 641 µm）で、フルスケールでの電界は約 0.2 V/mm。電界による電圧係数は長さの 2 乗に反比例するので、この長さでは許容よりずっと小さいはず。確かめられるのは実機だけ（フルスケールの HD3）。

**オフセット DAC の MIM のばらつき（`margin_fig.py`）。** 抽出のビットの重み（`figs_perf.dac_weights`：各ビットの MIM と配線）に、ビットの MIM ごとの乱数の誤差（仮の係数 1.41 %·µm の 1、2、4、8 倍。半分ずつ引いて平均）を足し、20,000 ダイで段と残差を見た。
- 2 倍まではどのダイも単調で、最大の残差（ダイの 99.9 %）は今と同じ（範囲 1 で 154〜157 µV、範囲 2 以上で 167 µV）。
- 4 倍では、範囲 3、4 のダイの 0.2〜0.3 % が桁上がり（255→256、511→512）で単調でなくなる（最大 15 µV ほど戻る）。残差は 169 µV で、運転中に M を動かさない窓（ADC の入力で ±54 mV、電極換算 188 µV）の内側。
- 8 倍では、範囲 3、4 のダイの 9〜14 % が単調でなくなり、範囲 4 では 1.5 % のダイの残差が窓を出る。

**結論。** PDK にない係数は、どれも仮の値の 4 倍まで（電圧係数は約 300 ppm/V² まで）要求に影響しない。発注の前にチップを直す必要はない。実機では、フルスケールの HD3（電圧係数）と、DAC1 とオフセット DAC の段を確かめる。

## 同相の除去（CMRR）と電極の不釣り合い（11/17〜18、`cmrr.py`、図 44）

これまでの評価は、電極を片側 100 Ω の抵抗で置き、体（基準電極）は基板の VCM にあるとしていた。商用電源の同相が体に乗ったときに、どれだけ差動に変わるか（CMRR）は、まだ測っていなかった（`gf180_electrode_dc_20261022.md` でも「まだ評価していない」）。

**台。** `afe_startup.py` の start のデッキ（12 回目のチップの抽出した afe_top、eeg_bias、eeg_ref、チップの配線、パッド、ボンディングワイヤ、基板、電源投入から。typical、AVDD 3.3 V、AFE_IBIAS 3、5 ms に解除）に、11/17 に次を足した。既定のデッキは 11/16 までとバイト単位で同じ。
- `--cm A --fcm f`：体を基板の VCM に対して A mV pk、f Hz の正弦波で動かす。2.5 ms から 2 ms かけて包絡を上げる B 電源で入れる（折れ点を作らない）。`--cm 0` は電源が 0 V の同じデッキで、差し引く基準にする。
- `--zp`、`--zn`：電極 1 本ごとのインピーダンス（直列の項を + でつなぎ、並列は R|C）。不釣り合いは、ECG の規格の同相の試験の形（片側に 51 kΩ ∥ 47 nF）を ELP に入れた。
- 電極 1 本ごとに 0 V の電流の測りを入れ、電流の積分（qip、qin）を qo と同じように書き出す。

**解析（`cmrr.py`）。**
- 同相のランから基準のランを差し引く（立ち上がりの動きがちょうど消える）。同相そのものが残すゆっくりした動きは多項式（2 次）で取る。基準がまだ終わっていないランは単独で当てはめる（4 次。3 周期より短い窓は 2 次）。同相の周期の整数倍の窓で、チョッパ周期の平均を、同相の周波数とその 2 倍、3 倍に当てはめる。
- 電極にコンデンサのある脚（R|C）は、その時定数の指数と 1 次の補正（x e^−x、x = (t − t0)/τ、t0 は窓の始め）も当てはめる（11/18 に足した。理由は下の「解除までの同相の容量」）。
  - 指数を入れるのは、AFE の出力とピンの差動だけ（11/18 の朝に直した）。チップの側（体、基板の VCM、増幅器の入力のコモンモード、脚の電流）には、この成分がないので入れない。理由は下の「50 Hz の結果」の「1 周期の当てはめ」。
- 脚が不釣り合いのランでは、ピンの差動（v(ELP) − v(ELN)、シミュレーションのまま）も出力と同じ形で当てはめる。出力との比は、その周波数での AFE の利得になる。釣り合いのランのピンの差動は、入力チョッパの切り替えの分だけで、増幅器はこれをこの利得では受けないので、出さない。
- 当てはめを変えたときの出力の広がり（多項式を 1 次下げる。時定数を 0.9 倍と 1.1 倍にする）も出す。
- Vcm は、体の接地に対する実際の動き（v(body)）にした（11/17 の午後に直した）。脚の電流は基板の VCM（基準電極の節点）を通って戻り、VCM は CVCM 10 nF を通してその分動く（1 kHz で Vcm の 2.6 %、−165°）。そのため体は、電源の式の 0.9754 倍（−0.39°）しか動かない。
- AFE の出力は、図 38 の typical のラン（2 kHz、フルスケール）の利得 297.47（位相 −0.08°）で電極に換算する。
- 電極 1 本ごとの電流から、体から見たアドミタンス（コンダクタンスと容量）を出す。電極のインピーダンスで差動に変わる分と、チップ自身の分に分ける。
- `switches()`：入力チョッパの 8 個のスイッチ（ランのデッキの抽出の afe_top の素子）だけを、PDK のモデルの小さな AC のデッキにする。ソースとドレインを全部 1 つの節点（電極の DC の 1.648 V）につなぎ、ゲートは片方の相にする。スイッチの容量と、ngspice の既定の gmin が接合に入れるコンダクタンス、導通している組（PMOS と NMOS）のオン抵抗を出す（`runs/cmrr_r12/switches/`）。

- **不釣り合いの値は変わらない。** 帯域内で 1 kHz 286.20 µV pk（チョッパ周期の平均 285.84 µV と 0.13 %）、50 Hz 194.15 µV pk（193.97 µV と 0.09 %、54.24 dB）。結論（ほぼ全部が電極の側、CMRR のためにチップを直す必要はない）は同じ。
- 図 44 の (b)（釣り合いの波形）と (d)（釣り合いの線）は帯域内の値に直した（11/18 の夜）。PSRR の解析（`psrr.py`）は初めからこの方法でとる。

**読み。**
- チップ自身の変換は小さい（帯域内で 1 kHz 148 dB、50 Hz 147 dB。11/18 の夜までの「1 kHz で 105 dB」は見かけ）。電極の不釣り合いによる変換は、同相の入力アドミタンス（50 Hz で 47.7 nS、21 MΩ。ほとんどが 140.6 pF の容量）で決まる。
  - その半分は入力スイッチの容量。スイッチのオン抵抗は今 0.45 Ω（導通している組、電極の DC で）で、電極の 100 Ω に比べてずっと小さい。ただ、スイッチを 4 分の 1 にしても 50 Hz の変換の改善は約 3 dB（全部なくしても約 5 dB）。スイッチの容量は、入力インピーダンスの差動（Cpf の打ち消し）、チョッパの電荷の注入、レイアウトにも効く。
  - もう半分は Cin を通る分で、増幅器の入力のコモンモードを体に追わせない限り残る。
- 基板の側では、体の同相を小さく保つこと（基準電極を低いインピーダンスで VCM へ、右足駆動）と、電極のインピーダンスをそろえること（濡れた電極）で決まる。体の 50 Hz の同相がどれだけになるか（何 mV を前提にするか）は、まだ決めていない。
  - 変換は同相に比例する。51 kΩ ∥ 47 nF では、同相 X mV pk で電極換算 1.94 X µV pk。フルスケール（0.943 mV pk）に届くのは、同相が約 490 mV pk のとき。
- **今回 rev の構成決定には影響しない（CMRR のためにチップを直す必要はない）。** チップの側で変えられるのはスイッチの大きさくらいで、4 分の 1 にしても 3 dB。51 kΩ ∥ 47 nF と 100 mV pk でも、ADC の範囲の 21 % に収まる。

**ラン（11/18）。**
- 50 Hz の 2 本は 11/18 の 5 時 40 分ごろに終わり、図 44 を仕上げた。同相 0 の基準 2 本は 1 時 45 分に終わり、1 kHz を当てはめ直した。

不釣り合いのランで見つけた、AFE_RST を上げているあいだの入力と、DAC で打ち消したオフセットが電極に流す電流は、次の節（電極に抵抗とコンデンサがあるときの起動）に移した。

## 電極に抵抗とコンデンサがあるときの起動と、DAC で打ち消したオフセットの電流（11/18〜、図 45、`afe_saturation.py --zp --chop-hold`、`electrode_start_fig.py`）

**AFE_RST を上げているあいだの入力と、DAC で打ち消したオフセットが電極に流す電流（11/18）。**

未明の見立て（2 時 1 分にランを回し始めたときのもの。下の「朝に直した」で一部を直した）：

  - チョッパが止まっているあいだ（3.0〜4.8 ms）は容量（368 pF）だけ。~~解除のあとは MΩ（DC で 3.54 MΩ）~~（朝に直した。DAC で打ち消したオフセットには、解除のあとも 5.4 kΩ）。

  - ~~見積もり（51 kΩ ∥ 47 nF、300 mV）：パルスのあと 47 nF に約 160 mV 残り、2.4 ms の時定数で抜けるので、AFE が範囲に戻るのは書いてから約 12 ms。~~（朝に直した。解除のあとも同じ負荷なので 47 nF は抜けない）

- 電流は、チョッパの切り替えのたびに Cin をオフセットまで充電し直すスパイクで流れる（300 mV では、ピンが一瞬 27 mV まで下がり、約 0.4 µs で戻る）。100 Ω の電極では半周期の中で戻るので、増幅器は 300 mV を見て、M 997 で打ち消せる。チョッパが止まっているあいだ（4.0〜4.8 ms）は流れない。
- Cpf の正帰還は、増幅器の出力に出ている分の電荷しか補わない。DAC は仮想接地でオフセットを打ち消すので、出力にオフセットは出ず、その分の充電は電極から来る（1/(2 f_ch C) で C は約 730 pF：Cin 636 pF とスイッチ、配線）。3.54 MΩ（図 23、24）は、増幅される信号に対する値。
- 飽和しているあいだは、Cpf が飽和した出力の分を入れるので、電極の電流は減る（図 39 の 300 mV で DAC を書く前、ピンの平均 296.6 mV、約 17 µA）。
- 未明の見立てのうち、解除のあとは MΩ という点が誤り。チョッパを動かしたままのリセットも、DAC で打ち消したあとも、オフセットから見た負荷は同じ 5.4 kΩ。

**これで分かること。**
- **電極を通る DC の電流。** 抵抗の小さい電極では、オフセット / 5.4 kΩ（10 mV で 1.8 µA、30 mV で 5.4 µA、300 mV で 54 µA）が、オフセットを打ち消しているあいだずっと流れる。DAC の 1 段（0.30 mV）あたり 56 nA。
  - 10/23 に決めた要求（電極 1 本あたり 1 nA 以下。`gf180_pex_20261023.md` の「判定（電極側の要求）」。そのときはチャージポンプの 36.6 nA を不適合として直した）を、DAC を使うと（M が 1 以上）大きく外れる。
  - 安全の上限（患者補助電流、DC で正常状態 10 µA）には、抵抗の小さい電極でオフセット約 54 mV で届く。
  - CHOP_FAST = 0（64 kHz）にしても半分になるだけ。電流を消すには、打ち消したオフセットの分の電荷を電極の側（Cin の入力の側）でも補う必要がある（例：オフセット DAC と同じ符号で動く容量をもう 1 組、入力の側に置く）。チップの変更になる。
- **電極に抵抗 R_e があると、ピンに届くオフセットは V_off × 5.4 kΩ / (5.4 kΩ + R_e)。** 51 kΩ ∥ 47 nF と 300 mV では 28.4 mV（電流 5.3 µA）。~~DAC の符号はこれに合わせることになり（M 約 94）~~、電極の抵抗が変わるとピンのオフセットが動く（~~300 mV、51 kΩ で 0.50 µV/Ω。1 kΩ でフルスケールの 53 %~~。11/18 の夕方に直した：解除のあとチップは M で決まる電流を流す電流源としてふるまう（下の「G の結果」）ので、感度は電流そのもので、300 mV、51 kΩ で 5.3 µV/Ω（範囲の中心から約 0.3 kΩ で ADC の範囲を出る）。0.50 µV/Ω はチップを 5.4 kΩ の抵抗とみた値で、51 kΩ では約 10 倍小さく見積もっていた）。
  - （11/18 の昼に直した。28.4 mV はピンの単純な平均で、増幅器が取り込むのはチョッパが切り替わる直前の値（約 1.3 mV 高い）。また解除のあとは打ち消した分だけが電流を流すので、M はリセット中の値に合わせても合わない。M 94 の E と F は範囲に戻らなかった。下の「E と F の結果」）
- **D（電極 100 Ω、AFE_RST のあいだ CHOP_EN を下げる）。** パルスのあいだ、ピンの差動は 300.000 mV（電流なし）、増幅器の入力は VCM。解除と同時にチョッパが動き出し、最初のチョッパ周期だけ出力が −30 mV（電極換算 −0.1 mV）ずれ、ADC の範囲を 0.4 µs だけ出るスパイクがある。そのあとの入力のコモンモードは、はじめから釣り合いの値（1.6505 V。VCM_AFE と同じで、動かない）にある。
  - 図 27 は、入力のコモンモードが 19 mV 低いところから時定数約 47 ms で近づいている途中（3 ms で 0.4 mV/ms）で、出力はそのぶん D より 0.85 mV（電極換算 2.9 µV）低い。11/16 の手順（パルスのあいだもチョッパを動かす）は 14 mV 低いところから近づく（解除から 2.5 ms で 0.65 mV、2.2 µV 低い）。どれも 45 mV/V（出力／入力のコモンモード、M 997）で説明でき、DAC の残差（最大 166 µV）よりずっと小さい。
  - 電極 100 Ω では、どちらの手順でもよく、CHOP_EN を下げるほうが釣り合いに近い。
- **電極に抵抗とコンデンサがあると、見立てが逆になる（見込み。E と F で確かめる。11/18 の昼に一部を直した：解除のあとは打ち消した分だけが電流を流すので、M が合っていないと、電極は解除のあとも動く。下の「E と F の結果」）。** チョッパを動かしたままのパルスは、そのあとと同じ 5.4 kΩ なので、電極の状態を動かさない。CHOP_EN を下げると、パルスのあいだだけ負荷が消え、47 nF は 300 mV へ向かって動く（100 µs で行き先までの 4 %、ピンで約 11 mV）。解除のあと、電極の時定数（51 kΩ ∥ 5.4 kΩ と 47 nF で 0.23 ms）で戻るまで AFE は範囲を出る。
  - 最初の書き込みの前は AFE が飽和していて負荷が違うので、書いたあと、電極が 5.4 kΩ の負荷に落ち着くまでには 0.23 ms の数倍かかる。パルスをそのあいだ（約 1 ms）伸ばせば、電極はリセット中に落ち着く。
- **RTL の CONTROL のリセット値（CHOP_EN = 1）は変えないことを勧める。** 電源投入で RESET_N から解除までチョッパが動いていると、電極は解除のあとと同じ負荷に先に落ち着く。パルスのあいだ CHOP_EN をどうするかは、ホストの手順で決められる。

**B の結果：M が電極に合っていないと、AFE は逆向きに飽和したまま残り、チップが電極を逆へ引っ張る（11/18 の 6 時 21 分に 10 ms まで回った。図 45）。** ELP に 51 kΩ ∥ 47 nF、300 mV、M 983、AFE_RST のあいだ CHOP_EN を下げる（最初のリセットも）。電極の電流は、脚に保存した電荷（qip）から。
- 最初のリセット（4.8〜5.0 ms）はチョッパが止まっているので、ピンの差動は 299.7 mV で、電流は流れない。
- DAC を切ったまま解除すると AFE は飽和し、ピンは時定数 0.74 ms で約 72 mV へ向かって下がる（書く直前に 132 mV。5.5〜6.0 ms の電流の平均 7.9 µA）。飽和したチップは、ピンから見て約 0 V と約 23 kΩ（線形と見たとき。電極 100 Ω の図 39 では 17.5 µA）。
- パルスのあいだ（CHOP_EN が低い）は負荷が容量だけになり、ピンは 300 mV へ戻りかけて、解除のときに 116 mV。M 983 は 295.8 mV を打ち消すので、増幅器は約 −180 mV を見て、逆向きに飽和する。
- そのあと、ピンは −349.0 mV へ時定数 0.57 ms で動き、10 ms で −348.0 mV。電極には 12.7 µA（解除の直後は 8 周期の平均で最大 40 µA）が流れ続け、ADC の入力は −1.80 V（範囲 ±0.484 V の外）のまま。
  - 行き先と時定数から、逆に飽和したチップは、ピンから見て約 −0.55 V と約 16 kΩ（線形と見たとき）。オフセットと逆向きにピンを引くので、AFE はひとりでは戻らない。仮想接地が保たれないので、DAC の電荷が Cin を通して電極の側に出ていくと見ている（見立て）。
  - 電極 100 Ω（D と図 39 のパルスのラン）では、同じ書き込みとパルスで、解除と同時に範囲に入る（電極がピンを 300 mV 近くに保つ）。
- **読み。**
  - ホストは −フルスケールを読むので、探索の向き（M を下げる）は正しい。ただ、合わない M のあいだはチップが電極に 10 µA を超える電流を流しうるので、合わない M を残したまま待たない。
  - パルスのあいだ CHOP_EN を下げると、ピンは解除のあとと違う値（オフセットの側）へ動くので、解除のときの比べが狂う。電極に抵抗とコンデンサがあるなら、パルスのあいだもチョッパを動かす（朝の勧めのとおり）。

**E と F の結果：M 94 では、パルスが 1 ms でも 100 µs でも、AFE は範囲に戻らない（11/18 の 11 時 58 分に 10 ms まで回った。図 45）。** ELP に 51 kΩ ∥ 47 nF、300 mV、M 94、範囲 4、パルスのあいだもチョッパを動かす。E はパルス 1 ms、F は 100 µs。
- ここから、ピンは「落ち着いたピン」で見る。増幅器が取り込むのは、入力チョッパが切り替わる直前のピンの電圧（Cin を充電し直すスパイクが収まったあと）。そこで、各切り替えの 0.3 µs 前の値を 8 周期で平均した。ピンの単純な平均は、脚の 100 Ω に流れるスパイクの電圧降下のぶん低い（51 kΩ の電極で約 1.3 mV、100 Ω の脚で 300 mV のとき 11 mV。図 39 の 300 mV のランでは、落ち着いたピンは 300.000 mV で、平均は 289.2 mV）。増幅器の入力は、落ち着いたピン − M × 0.301 mV。ADC の範囲は、増幅器の入力で ±1.63 mV（±0.484 V / 297.5）。
- M 94 は、ピンの単純な平均（28.4 mV）に合わせて選んだ。増幅器から見ると足りなかった（選び方の誤り）。
- **E（1 ms）。** パルスのあいだ、落ち着いたピンは書いたときの 91.1 mV から時定数約 0.24 ms で下がり、解除のとき 31.3 mV（電流 5.52 µA。リセット中のチップは約 5.7 kΩ に見える）。
  - 増幅器の入力は解除のとき +3.0 mV で、はじめから範囲の外。
  - そのあと時定数 0.40 ms で +5.0 mV に動く。10 ms で ADC の入力は +0.99 V（範囲 ±0.484 V の外）、電流 5.232 µA。
  - 増幅器の仮想接地の誤差は 0.37 mV で、範囲の中（図 39 のラン、0.008 mV）より大きい。出力は 1.04 V で振り切ってはいない（飽和は約 1.8 V）が、少し圧縮されている。
- **F（100 µs）。** 解除のとき落ち着いたピンは 76.0 mV で、増幅器は +47.7 mV を見て飽和する。
  - ピンは下がっていく。ADC の入力の平均は 6.6 ms ごろ 0.15 V まで下がり、範囲に入ったように見える。
  - このとき増幅器はまだ飽和している（仮想接地の誤差 14 mV）。平均が 0 近くを示してだまされるのは、11/16 の図 39 と同じ。

- **パルスの長さは、行き着く先を変えない。行き着く先は M で決まる。** 100 µs では解除のあと約 1.5 ms 飽和したまま動く。1 ms では、解除のときに電極がリセット中の釣り合いに近い。
- 範囲に入っているかは、ADC の入力の平均が ±0.484 V の内側にあることと、仮想接地の誤差が 1 mV より小さいことの両方で判定した。`electrode_start_fig.py` を、落ち着いたピン、仮想接地の誤差、増幅器の入力の当てはめで描き直した。

**読み（下の G で確かめた）：解除のあとは DAC で打ち消した分だけが電流を流す。そのため電極の電圧降下が M で動き、M の 1 段は増幅器の入力で約 3 mV になる。**
- 解除のあとは、Cpf が増幅器の出力に出ている分（残差）の電荷を補う。電極の電流は、打ち消した分の M × 0.301 mV / R_sc で決まる。
  - R_sc は約 5.56 kΩ（図 39 のラン、線形の状態で 300 mV / 53.98 µA）。ピンが約 30 mV の G では 5.67 kΩ（M × 0.301 mV / 電流）。
  - E の終わりの 5.232 µA は、M 94 の 28.3 mV / 5.56 kΩ = 5.09 µA に、圧縮で補いきれない残差の分が足されたものと見ている。もしピンの電圧全部が 5.56 kΩ を見るなら、33.3 mV で 5.99 µA になる。
  - リセット中は、チョッパが動いていれば、ピンの電圧全部が約 5.7 kΩ を見る。
- そのため、落ち着いたピンは 300 mV − 51 kΩ × M × 0.301 mV / R_sc。増幅器の入力は 300 mV − M × 0.301 mV × (1 + 51 kΩ / R_sc) になる。
- **M の 1 段は、増幅器の入力で 0.301 mV × (1 + 51 k / R_sc) 動く。** R_sc 5.67 kΩ（G）で 3.0 mV。ADC の範囲（±1.63 mV、幅 3.25 mV）とほぼ同じ。
  - 範囲に入る符号は高々 1 つ。最良の符号でも、オフセットの値しだいで最大 ±1.5 mV（ADC の範囲の 94 %、フルスケール 0.943 mV pk の 163 %。昼は「フルスケールの 94 %」と書いていた）が残る。
  - オフセットの大小によらない（オフセットが約 1.6 mV を超えて DAC を使えば同じ）。
  - 電極の抵抗が約 55 kΩ（R_sc 5.67 kΩ で。昼は 5.4 kΩ で約 53 kΩ と書いた）を超えると、どの符号でも範囲に入らないオフセットが出てくる。
  - 抵抗の小さい電極では小さい。10 kΩ なら 1 段 0.84 mV で、残りは最大 ±0.42 mV（ADC の範囲の 26 %、フルスケールの 45 %）。
- 運転中の手順（「使い方」の 5。0.6 段で M を 1 動かす）も、抵抗の大きい電極では 1 段が約 3 mV になるので、そのままでは使えない。
- 原因は、朝に限界として記録した DAC で打ち消したオフセットの電流（約 5.6 kΩ）と同じ。電極に DC 電流を流すだけでなく、抵抗の大きい電極では打ち消しの細かさを (1 + R_e / R_sc) 倍粗くする。
  - G で確かめたので、チップを直すかどうかをユーザーに判断をあおいでいる（11/18 の夕方。下の「G の結果」）。

  - R_sc は、ピンが約 30 mV のここでは 5.67 kΩ、300 mV（図 39）では 5.56 kΩ。
  - R_sc 5.67 kΩ で計算すると、M 100 の増幅器の入力は −0.78 mV（ピンの DC の平均で）。当てはめは、落ち着いたピンで −0.60 mV、ホストの読みで −0.79 mV。
- **M の 1 段は、直線の範囲で 0.301 mV × (1 + 51 kΩ / 5.67 kΩ) = 3.0 mV。** ホストの読みでは、M 99 → 100 は 2.42 mV（落ち着いたピンで 2.55 mV）。M 99 は範囲の端で圧縮が始まっていて、電流が直線の場合より 8.5 nA 多い（51 kΩ で 0.43 mV 引き戻す）ので、そのぶん小さい。電極 100 Ω の 1 段（0.30 mV）の 8〜10 倍。
- **範囲の外では、チップが残差の一部も引き込み、電極を引き戻す。** 増幅器の出力が範囲を出るあたりから利得が圧縮し、Cpf が残差を補いきれない。直線の場合より多い電流（M 98 で 47 nA、M 94 で 243 nA）が 51 kΩ で残差を押し戻すので、M 98 と M 94 は +2.55 mV と +3.33 mV で止まり（直線なら約 +5.2 mV と +17 mV）、時定数は 0.35〜0.40 ms と短い。読みの符号は M の向きのとおり（94、98、99 は＋、100 は −）で、探索の向きは崩れない。
- **ホストは、電極が落ち着くまで待って読む。** 10 ms（解除の 3 ms あと）では、M 99 は +0.438 V で範囲の中に見えるが、落ち着く先は範囲の端（+0.485 V）。51 kΩ ∥ 47 nF では、1 段ごとに 5 × 2.4 ms = 12 ms 待つ。実際の電極は C が大きいほど長いので、読みが動かなくなるまで待つ。
- **最良の M 100 でも、残差は −0.79 mV**（ADC の範囲の 48 %、フルスケール 0.943 mV pk の 84 %）。−側の余白は 0.84 mV で、フルスケールの正弦波は入らない。EEG の普通の信号（100 µV 程度）は入る。電流は 5.31 µA で、安全の上限（10 µA）の内側、10/23 の要求（1 nA）は外れたまま。
- **電極の抵抗の変化への感度は、電流そのもの。** チップが電流源なので、電極の抵抗が ΔR 変わると、ピンは電流 × ΔR 動く。ここでは 5.31 µV/Ω で、範囲の中心からでも約 0.3 kΩ（0.6 %）の変化で ADC の範囲を出る（M 100 の状態からは、抵抗が 0.16 kΩ 増えると出る）。上に書いた 0.50 µV/Ω（チップを 5.4 kΩ の抵抗とみた値）の約 10 倍。オフセット 10 mV、電極 5 kΩ でも約 0.9 µV/Ω で、1 %（約 50 Ω）の変化が約 48 µV になる。バイアス電流が nA 以下の普通の増幅器より 3 桁大きい。
- **まとめ。**
  - アクティブ電極（電極のそばのバッファ。チップから見て約 100 Ω で、仕様の条件と同じ）なら、1 段は 0.31 mV のままで、皮膚には電流が流れず、この問題は出ない。バッファは、DC で最大 54 µA と、チョッパの切り替えのたびのスパイクを流せること。
  - パッシブ電極を直接つなぐと、電極の DC の抵抗が約 20 kΩ までなら打ち消しは使える（1 段 1.36 mV 以下）が、電極の抵抗の変化への感度が大きい。50 kΩ 前後では範囲に入る符号が 1 つだけで、約 55 kΩ を超えると入らないオフセットが出る。
  - チップを直す（打ち消した分の電荷を Cin の入力の側でも補う）かどうかを、ユーザーに判断をあおいでいる（11/18 の夕方）。
- E と F は、6 時 12 分に始めたものが 8 時 40 分ごろ Claude Code のセッションの終わりで止まり、8 時 47 分からターミナルのタブで回し直した（`runs/elec_r12/run_EF.sh`）。A（M 983、11/16 の手順）は回し直していない（B と同じく逆に飽和する見込み）。

## 電源の除去（PSRR）とレギュレータへの要求（11/18〜19、`psrr.py`、図 46）

これまでの評価の電源は、レギュレータを出力抵抗 0.05 Ω の理想の電圧源とし、雑音もリップルもなかった（上の「電源、基準、バイアスの定常の動き」）。レギュレータの雑音とリップルが出力にどれだけ出るか（PSRR）を、11/18 の夜から回した。

**台。** `afe_startup.py` の start のデッキ（CMRR と同じ。12 回目のチップの抽出、チップの配線、パッド、ボンディングワイヤ、基板、電源投入から。typical、AVDD 3.3 V、AFE_IBIAS 3、5 ms に解除、`--cm 0 --fcm 50`）に、11/18 に `--rip AVDD|DVDD` を足した。
- 片方のレギュレータの出力（0.05 Ω の手前）に、10 mV pk の音を 4 つ乗せる。1 kHz と、128 kHz × k + (1 + k/4) kHz（k = 1、2、3 で 129.25、257.5、385.75 kHz）。2.5 ms から 2 ms かけて包絡を上げる B 電源で入れる。
- 2 つのチョッパの間に入ったリップルは、出力のチョッパでその高調波の分だけずれて出る。高調波 k のそばの音は (1 + k/4) kHz に来るので、音ごとに出る周波数が違い、1 本のランで分けて読める。どの音もチョッパの高調波も、窓（6〜10 ms）にちょうど整数周期入る。
- リップルのないデッキは前とバイト単位で同じで、CMRR の同相 0 の基準 2 本がそのまま基準になる。基板の AVDD_BRD と DVDD_BRD（チップのそばの基板の節点。レギュレータの雑音とリップルの仕様が指す場所）も書き出す。
- 電極は釣り合い（片側 100 Ω）と、ELP に 51 kΩ ∥ 47 nF の 2 通り。AVDD と DVDD で 4 本。

**解析（`psrr.py`）。**
- 基準を差し引き、出力は帯域内（チップの CIC が見る値）で読む。62.5 µs の箱形の平均を 3 回、正確な積分 qo からとり、音の出る周波数に当てはめて、箱形の sinc³ と遅れを戻す（CMRR の「帯域内の値」と同じ方法）。電極換算は AFE の利得 297.47。
- リップルは、基板の節点とチップの上（AFE の AVDD − AVSS、パッドリングの DVDD − DVSS）で、100 ns の格子のまま当てはめる。PSRR は基板のリップルに対して出す。チップの上の AVDD のリップルは基板の 98.8〜99.7 %。
- 音ごとに、2 つのチョッパの間の変換（増幅器の出力 OPI − ONI。出力のチョッパの前）も当てはめる。出力のチョッパの奇数次の高調波 k は、その (2/π)/k を帯域に持ってくる。
- 1 kHz の音では、脚の電流から脚 1 本の電源へのアドミタンスを出し、電極の側の分（脚の電流 × それぞれのインピーダンス）とチップ自身の分に分ける。増幅器の入力のコモンモードとピンのコモンモードも当てはめて、AVDD への容量を分ける。入力スイッチだけの分は `switches_supply()`（入力チョッパの 8 個のスイッチだけの AC で、AVDD を動かす。`runs/psrr_r12/switches/`）。
- 帯域（0.5〜100 Hz）へは、1 kHz の脚のアドミタンスを平らとして脚のインピーダンスを通し、釣り合いのランのチップ自身の分を大きさで足して延ばす。AVDD では、ngspice の既定の gmin がスイッチの PMOS の接合に入れる脚 1 本 4.09 nS（実物にはない）を除く。AVDD の 50 Hz は回していない（同相では、脚のアドミタンスは 50 Hz と 1 kHz で 1.5 % しか違わなかった）。
- 確かめ：基準なしで単独に当てはめても（多項式 4 次）、折り返した音は 5 桁合う（21.0832 と 21.0829 µV）。床に近い 1 kHz と 257.5 kHz の音は合わない（片側 100 Ω の 1 kHz で 142.9 と 139.1 dB）。脚のアドミタンスは、ELP と ELN の和は合うが、分け方に起動の漂いが入る（±3 pF、±7 nS）。基準だけに当てはめた床は 0.0001 µV 以下で、当てはめを変えた広がりは折り返した音で 0.01 % 以下。

**結果（4 本とも 11/18 の 21 時 44 分に始め、11/19 の 0 時 50〜58 分に 10 ms まで回った。typical）。** 電極換算の帯域内の出力（µV pk）と、基板のリップルに対する PSRR。

- **低い周波数のリップルは、チョッパで十分に除かれる。** 釣り合いで AVDD の 1 kHz は 139 dB、DVDD は 197 dB。チップ自身の変換は、どちらの電源でも問題にならない。
- **AVDD の 128 kHz の奇数倍のそばのリップルは、チップ自身で 52 dB しか除かれない（電極によらない）。**
  - 2 つのチョッパの間で、AVDD のリップルは増幅器の出力 OPI − ONI に差動として 1.10 V/V で出る（129〜386 kHz で平ら。1 kHz では 0.72 V/V）。出力のチョッパの高調波 k はその (2/π)/k を帯域に持ってくるので、129.25 kHz は 1.25 kHz に 20.70 µV（測った値 21.08 µV、98 %）、385.75 kHz は 1.75 kHz に 4.41 µV（4.91 µV、90 %）と見込める。偶数次（257.5 kHz）は出力のチョッパの矩形波にない成分なので、帯域に来ない（0.0017 µV、132 dB）。
  - 1 kHz の 0.72 V/V は、ADC の入力に 128 kHz の矩形波として出る（0.73 V/V。10 mV のリップルで 7.3 mV、ADC の範囲 ±484 mV の 1.5 %）。帯域の外なので CIC が除く。
  - この変換は typical（ミスマッチなし）の抽出で出る。モンテカルロのダイでもほぼ同じ（下の「統計」）なので、ミスマッチではなく、配置か回路そのものの非対称から来る。どこから来るかは、11/19 に下の「変換の出どころ」で分けた（増幅器の入力 INN の余分な配線の容量、図 47）。DVDD の同じ変換は 0.5〜1.2 mV/V で、3 桁小さい。
- **51 kΩ ∥ 47 nF の不釣り合いでは、AVDD の帯域内は 50 Hz で 62.5 dB。** 1 kHz の 12.51 µV のうち 12.32 µV（98.5 %）が、脚の電流がそれぞれのインピーダンスで作る差動（電極の側）。脚 1 本の AVDD への容量は 1 kHz で 59.0 pF（ELP 58.2 pF、ELN 59.8 pF）で、内訳は次のとおり。
  - 入力スイッチの PMOS のウェル 23.7 pF（`switches_supply()` の 23.97 pF から、ピンも 1.1 % 動く分を引く）。
  - Cin を通る分 23.9 pF。増幅器の入力のコモンモードが AVDD のリップルの 4.8 % 動き（ピンは 1.1 %）、Cin（636 pF）の両端に 3.75 % がかかる。
  - 残り 11.4 pF（パッド、配線。まだ分けていない）。
  - DVDD へは脚 1 本 2.1 pF で、帯域内は 50 Hz で 91.3 dB。
  - 変換は不釣り合い |ΔZ| に比例する（CMRR と同じ）。抵抗だけの 5 kΩ の不釣り合いなら、50 Hz で約 8 倍小さい（約 81 dB）。
- **AVDD の 128 kHz のそばの折り返しも、不釣り合いで大きくなる（47.5 dB）。** チョッパの間の変換が 1.10 から 1.47 V/V に増える。それで見込める 27.7 µV より測った値（36.9 µV）が大きく、ほかの道もある。INN の容量をそろえると（下の診断 C）、この増えた分もほとんど消える（36.94 → 1.63 µV。釣り合いでそろえた B の 1.11 µV の 1.5 倍）ので、ほかの道も INN の容量を通る。

**レギュレータへの要求。** 基板のチップのそばで平らな雑音とし、AFE の雑音 5.341 nVrms（0.5〜100 Hz）に 5 %（1.71 nVrms）足す大きさを出した。帯域内は |T| の 2 乗の積分から、チョッパの高調波 k のそばは両側（k × 128 kHz ± 0.5〜100 Hz）が帯域に重なるとして出した。

|---|---|---|---|---|
| 帯域内（0.5〜100 Hz） | 1.6 mV/√Hz | **234 nV/√Hz** | 1.2 V/√Hz | 6.4 µV/√Hz |
| 128 kHz ± 100 Hz | 51 nV/√Hz | 29 nV/√Hz | 63 µV/√Hz | 36 µV/√Hz |
| 256 kHz ± 100 Hz | 506 µV/√Hz | 4.7 µV/√Hz | 288 mV/√Hz | 140 µV/√Hz |
| 384 kHz ± 100 Hz | 139 nV/√Hz | 58 nV/√Hz | 130 µV/√Hz | 55 µV/√Hz |

- 5 倍より上の奇数次（640 kHz、896 kHz、…）は回していない。(2/π)/k で減るとして足すと、許せる雑音は約 5 % 下がる（片側 100 Ω で約 45 nV/√Hz）。10 Hz〜100 kHz で平らな雑音なら、45 nV/√Hz は 14 µVrms にあたる。
- 音（周期的なリップル）では、128 kHz の奇数倍 ± 100 Hz のリップルが、片側 100 Ω で 2.4 × 10⁻³ 倍、51 kΩ ∥ 47 nF で 4.2 × 10⁻³ 倍で帯域に出る。1 µV pk のリップルで 2.4 nV pk（1.7 nVrms で、5 % の大きさ）。
- チップのクロックから作られる周期の成分（チップ自身の電流、1 kSPS の読み出し）は、チョッパの倍数との差が 0 か 1 kHz の倍数になるので、DC か CIC の零に落ちる。チップ自身の電流の分は、もうシミュレーションに入っている。

**読み。**
- 帯域内の低い周波数のリップルは問題にならない（釣り合いで 139 dB 以上）。気をつけるのは、AVDD の 128 kHz の奇数倍のそばと、電極が不釣り合いのときの帯域内。
- **基板への要求にした（管理表 F2 の (4)）。** AVDD は、128 kHz と 384 kHz のそばの雑音が約 40 nV/√Hz 以下（51 kΩ ∥ 47 nF の電極では約 22 nV/√Hz 以下）、帯域内は 51 kΩ ∥ 47 nF で約 225 nV/√Hz 以下の低雑音の LDO にする（11/19 の 8 時に、下の統計のいちばんきびしいものから決め直した。typical では 45、25、234）。スイッチングレギュレータを AVDD に直接使わない。チップのクロックと同期しない周期の成分（スイッチングの周波数とその高調波など）を 128 kHz の奇数倍 ± 100 Hz に置かない。DVDD は 3 桁以上ゆるく、普通の LDO で足りる。
- チップの側で減らすなら、チョッパの間の変換（1.10 V/V）のほぼ全部を作っている INN の余分な配線の容量（AVDD に +1.96 pF、VBP に +0.53 pF、BLP に +0.16 pF）を INP にそろえる（下の「変換の出どころ」、図 47）。そろえた診断では 128 kHz のそばが 78.0 dB で、許せる雑音は typical で約 900 nV/√Hz になる。AVDD への 59 pF のうち Cin を通る 24 pF は、増幅器の入力のコモンモードを AVDD によらないようにすれば減る。51 kΩ ∥ 47 nF の電極でも、そろえた診断（C）で 128 kHz のそばは 74.6 dB、許せる雑音は約 600 nV/√Hz になる。そのときいちばんきびしいのは帯域内の約 225 nV/√Hz で、これは脚の不釣り合いからピンで入る分なので、そろえても変わらない。**11/19 の 13 時に、ユーザーが r13 で直すと決めた**（直し方は下の「変換の出どころ」の終わり）。

**統計（11/19 の 1 時 8 分〜7 時 57 分）。** AVDD、釣り合いで、モンテカルロ 8 ダイ（プロセスとミスマッチ。4 本ずつ）と MOS の角 ss、ff、sf、fs。どれも AVDD 3.3 V で typical と同じ（チップの AVDD はダイごとに 3.4 V 前後に合わせ、ss のダイは 3.45 V で使うが、そこでは回していない）。ターミナルのタブで回した（`runs/psrr_r12/run_psrr_mc.sh`）。基準のランはないので単独で当てはめる（typical で折り返した音は 5 桁合う）。図 46 の (e)。
- 8 ダイとも 10 ms まで回った（mc1〜4 は 2 時 59 分、mc5〜8 は 4 時 51 分。1 本 6575〜6799 s）。角 4 つは 4 時 52 分に始め、7 時 57 分に済んだ（1 本 10956〜11101 s）。
- 128 kHz のそば（1.25 kHz に戻る）は 52.1〜52.8 dB（8 ダイの平均 52.4、標準偏差 0.24 dB。typical 52.4）、384 kHz のそば（1.75 kHz）は 60.9〜61.6 dB（61.2、0.22 dB。typical 61.2）。チョッパの間の変換は 1.05〜1.13 V/V（平均 1.10、標準偏差 2.8 %。typical 1.10）。どのダイでも、測った値は (2/π)/k の見込みの同じ倍数（k = 1 で 1.02 倍、k = 3 で 1.11〜1.12 倍）。ダイごとの差は変換の大きさの差（プロセスによる ±4 %）で、ミスマッチで出たり消えたりするものではない。
- 角では、128 kHz のそばが ff で 51.5 dB（変換 1.23 V/V）、ss で 53.2 dB（0.99 V/V）、sf と fs は typical と同じ 52.4 dB（1.10 V/V）。384 kHz のそばは 60.3〜62.0 dB。角は MIM の角も一緒に変える（ff で 0.9 倍、ss で 1.1 倍）ので、変換は MIM の帰還容量に反比例して動く（下の「変換の出どころ」）。見込みとの比は角でも同じ（k = 1 で 1.02 倍、k = 3 で 1.10〜1.13 倍）。1 kHz でのチョッパの間の変換も同じ比で動く（ff 0.80、ss 0.66、typical 0.72 V/V）。
- 1 kHz と 257.5 kHz は、どのダイと角でも 130 dB 以上（単独の当てはめで、方法の床に近い値）。
