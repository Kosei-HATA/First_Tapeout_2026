### 16.5 bit の残差予算（電極換算、0.5〜100 Hz、10/22 更新）

目標は ENOB 16.5 bit。SNDR 101.1 dB、総残差は 5.88 nVrms（電極雑音は別評価）。

| 寄与 | 配分 (nVrms) | 現状 |
|---|---|---|
| AFE（チョッパ動作時の熱雑音と 1/f 雑音、入力 TG を含む） | 5.0 | **4.59**（新しい構成、実際のバイアス回路、typical。コーナーは 4.17〜5.06。10/22）。取り込み時の候補は 8.86 |
| ADC 熱雑音（RIN、DAC1 抵抗、OTA1） | 0.9 | 抵抗分 0.79（AFE 利得 318 で換算。利得 277 のままなら 1.15 倍） |
| DAC1 の切替誤差（系統的スキュー 5 ps） | 0.87 | 行動モデルで 117.7 dB |
| DAC2、量子化、ELD | 0.1 未満 | 196 dB 前後 |
| 基準電圧（差動、帯域内 1 µVrms 以下） | 0.5 | 外付けの低雑音基準が前提 |
| 歪み（AFE＋ADC、0.943 mVpk） | 2.0 | AFE はチョッパ動作で HD3 −122.5 dBc（0.50 nVrms 相当、出力チョッパのブランキング込み。取り込み時は −80.8 dBc）。ADC はトランジスタ DAC2 のループ（1 kHz、0.3 V pk、8 ms）で、HD2〜HD5 がその周波数の雑音床と同程度（−107〜−123 dBc）で、歪みとしては見えない。500 Hz・32 ms（理想 DAC2）では雑音床が −127 dBc まで下がった。HD2〜HD4 は −124〜−127 dBc だが、HD5 が −112.6 dBc で見えている（0.3 V pk。フルスケール相当に 5 乗で換算すると約 0.9 nVrms）。HD5 の原因を調べる。トランジスタ DAC2 版の 32 ms は実行中 |
| チョッパ由来（リップルの折り返し、残留オフセット）、クロックジッタ | 1.5 | 未評価 |
| 入力経路の抵抗（ELP／ELN。asig_5p0 の内部 Metal2 約 1.2 Ω ずつと、TG までのストラップ） | — | 1.5（2 パッド並列で差動 1.2 Ω、ストラップは片側 0.1 Ω 以下として差動 1.4 Ω。1 本ずつなら 2.0）。10/22 のパッドリング試作で判明し、予算 v1 にはなかった |
| 合計（二乗和） | 5.75 | AFE 4.59、入力経路 1.5、ADC 側を利得 277 で換算すると 5.65（16.6 bit 相当） |

- 雑音の基準は、片側 100 Ω の低インピーダンス信号源とする（チップ自身の性能）。電極抵抗による増加（入力電流雑音）は、電極込みの評価で扱う。
- CCIA は入力チョッパが Cin の前にある。そのため、入力節点の DC 経路の雑音は出力チョッパでチョッパ周波数に移され、帯域には残らない。DC 経路は、PVT で値が変わらないスイッチト・キャパシタの抵抗（約 780 MΩ）にした（B7）。
- 1/f 雑音はチョッパ周波数に移るが、その周波数とその高調波での 1/f 密度は帯域に戻る。取り込み時の候補では、これが 7.00 nVrms あった。評価は静止解析の高調波和で行い、チョッパ動作の過渡解析の利得で確かめる。
