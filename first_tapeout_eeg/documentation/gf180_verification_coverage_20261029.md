# チップが動くために成り立つべきことと、それを見ている検査（10/29）

10/29 に、コアの DVDD がどの DVDD パッドにもつながっていないことが、外部の確認で見つかった（r0〜r7 のすべての版。`gf180_chip_assembly_20261023.md` の「組み直し（10/29、8 回目）」）。

- DRC 違反なし、コアの LVS 一致、precheck 通過のままだった。どの検査も、コアとパッドの境目を見ていなかった。
- 検査はそれぞれ見ている範囲が違う。全部通っても、チップが動くとは限らない。

同じような穴を探すため、チップが動くために成り立つべきことを書き出し、それぞれをどの検査が見ているかを表にした。

記号：✅ 毎回の流れか記録のある確認で見ている／▶ 一部だけ、または実行中／⚠ どの検査も見ていない（穴）

## 穴の一覧と次の手（優先の順）

1. **コアとパッドの境目**：10/29 に塞いだ（`connect_check()`、チップ全体の LVS、`supply_check.py`、8 回目のチップ）。チップ全体の KLayout の LVS は、デッキの扱いを直したあと、r7（DVDD が切れている版）では DVDD の切れを出し、r9 では一致した。
2. **別の道具での照合**（Magic の抽出と Netgen）：IO セル（コーナーは下のセルを平らにして）、adc_top、チップ全体（r8、r9。IO セルの中を平らにして）が一致。
3. **ADC のデジタルの電源の電流密度**：10/29 に確かめた。ゲートレベルのシミュレーションのスイッチングで、ADC のデジタル部は 1.38 mA（ff −40 °C 3.6 V）。Metal4 の渡りの上限 4.0 mA に 2.9 倍の余裕があり、太くしない。
4. **AFE の AVSS の電流密度**：Metal4 の渡り 2 本が、typical で上限の 87 %（+3σ で 101 %）だった。10/29 のユーザーの判断で、9 回目のチップで同じ大きさの Metal3 を下に足し、46／42 %（+3σ で 53／48 %）にした。渡りの下を通っていた 10 本（チョッパのクロック、制御、VBN、VBCM）は、その部分だけ同じ列のまま Metal2 に下ろした。パッドは最大 81 %。
5. **ESD の見直し**：電極の入力（ELP／ELN）とアナログのパッドから、コアのゲートまでの経路。
6. **デジタルの雑音のアナログへの入り方**：見積もり。
7. **レギュレータの雑音（PSRR）**。
8. 温度と、MIM と抵抗の素子ごとのばらつき：今回はユーザーの指定と PDK の制約で、このまま。

## 電力の出し直し（10/29、`gf180/tapeout/digital/power/run_power.sh`）

LibreLane の STA の電力は、OpenSTA の既定のスイッチングの率（入力が毎周期 0.1 回）で、ADC のデジタル部では論理がフレームに 1 回しか変わらないことを見ていない。

- 刺激：tb_e2e の s4 の符号列（32 Hz のフルスケール、DC 44.5 mV。`rtl/run_e2e.sh`）。LibreLane の 2 つのネットリストを、RTL と並べて遅延なしで動かした（`rtl/tb/gl_shadow.sv`。39,321 周期のすべての MCLK で RTL と一致）。
- 記録：0.2〜1.2 ms（1,024 フレーム）の VCD。OpenSTA の `read_vcd` で、ADC のデジタル部は 7,068 ピンすべてに動きが付いた。
- 電力：最終のネットリスト、SDC、SPEF（nom／min）で `report_power`。既定の率で回すと、LibreLane の値（26.0 mW、21.2 mW）をそのまま再現する。

| マクロ | 既定の率（tt） | シミュレーションの動き（tt 25 °C 3.3 V） | 同じ（ff −40 °C 3.6 V） |
|---|---|---|---|
| ADC のデジタル部（eeg_adc_dig） | 26.0 mW（7.88 mA） | 4.13 mW（1.25 mA）。クロック 2.57、フリップフロップ 1.13、組み合わせ 0.43 mW | 4.98 mW（1.38 mA） |
| デジタルブロック（eeg_digital_top） | 21.2 mW（6.42 mA） | 14.4 mW（4.36 mA）。フリップフロップ 8.44、クロック 5.72 mW | 17.1 mW（4.75 mA） |
