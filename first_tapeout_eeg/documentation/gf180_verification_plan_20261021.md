# GF180 今回 rev の検証計画（GDS 提出 12/16 まで）

2026-10-21 作成。今回 rev はこの計画で進める。凍結ではなく、今回 rev の進め方としての暫定採用であり、rev 以降も改善は続ける。

数値の根拠は、独立環境（Codex、`/Volumes/mukiebi/Codex/gf180_ishi_env_20261015/`）の 10/20〜10/21 の記録と本リポジトリの文書である。

## 目標と前提

- **目標**：AFE＋ADC＋実装デジタル単体で実効 16.5 bit。条件は電極側 0.943396 mVpk、帯域 0.5〜100 Hz とする。
  - SNDR は 101.10 dB、総残差は電極換算で 5.88 nVrms となる。
  - 設計上の余裕 3 dB を見込むと、104.10 dB／4.16 nVrms になる。
- **電極雑音は別に評価する**：信号源抵抗の熱雑音は 16.5 bit に含めない（100 kΩ で約 406 nVrms）。
- **4 s／20 s の連続検証は提出前に行わない**
  - 受入基準 `acceptance_16p5_20261020.json` の stage 3 は、4 s／20 s の連続トランジスタ検証である。
  - 現在の速度では、1 本あたり 4 s で約 71 日、20 s で約 357 日かかる（楽観的な見積もりでも 1.4 日／7 日）。
  - 提出まで 56 日しかないため、提出前には実施しない。
- **雑音はブロック特性とモデルで示す**：通常の tran は素子雑音を含まない。長い過渡解析を回しても雑音込みの ENOB は得られないためである。

## 提出時に主張すること

- 主張は「16.5 bit を予測（較正モデル＋短窓トランジスタ照合）」までとし、達成の確認はシリコン評価で行う。
- 予測が 16.5 bit に届かなかった場合も提出は見送らず、その旨を明記して出す。

## 検証の 4 層

| 層 | 中身 | 何を示すか | 実施場所（案） |
|---|---|---|---|
| L1 ブロック特性（トランジスタ） | AFE：チョッパ周期雑音（側帯波の変換）、利得・位相、歪み、入力インピーダンス。ADC：ループ、OTA 雑音、比較器、DAC | 雑音源と非線形性の実測値が予算配分に収まるか | 独立環境 |
| L2 較正モデル | L1 の値を入れた AFE＋CT ΣΔ＋bit-true CIC | 受入行列（4 s／20 s、5 周波数 × 3 振幅、PVT・ミスマッチ・雑音シード）をすべてここで回し、SNDR の分布を出す | 独立環境 |
| L3 短窓 E2E（トランジスタ） | AFE＋ADC＋CIC の直結、31〜94 ms 程度を数本 | 同じ入力で、モデルとコード列・残差スペクトルが一致するか（雑音なし条件） | 独立環境 |
| L4 物理 | DRC／LVS、重要ブロックの PEX 再検証 | チョッパの寄生結合、AFE 入力節点、積分器・DAC の寄生で特性が崩れないか | リポジトリ |

- **L3 の所要時間（目安）**：31 ms で約 13 時間、94 ms で約 40 時間。独立環境で測った速度から換算した値で、起動を含む失敗区間の実測なので目安にとどまる。
- **L4 の比較指標**：「最初のチョッパ半周期の差動誤差」を PEX の前後で比べる。SKY130 では、この指標でチョッパの寄生結合（PHI→INN 5.3 fF）を検出できた。

判断ゲート 1 で決めること：

- **面積**（10/21 の見積もり：`gf180_area_estimate_20261021.md`）
  - 現候補（利得 318 系）は、そのままでは Half に収まらない。DAC2 の単位抵抗（106.7 MΩ × 62 本）だけで約 4.4 mm² あるため。
  - DAC2 を作り直せば合計 3.5〜5.5 mm²（Half Height の 70〜110 %）になるが、余裕はない。
  - Full は Run 3 で売り切れなので、Half Width か Half Height を選ぶ（Half Height を推奨）。
  - 独自パッドリングにするかどうかも、ここで決める。
- **利得配分**：AFE を ×31.8 にする（積分容量 1.95 nF／側）か、×318 にする（680 pF／側）かを決める。面積だけで見れば、×318 のほうが約 1.1 mm² 小さい。
- **クロック**
  - MCLK 32.768 MHz から、ADC 1.024 MHz（÷32）、チョッパ 64 kHz、出力 1 kSPS を作る体系に統一する。
  - `gf180_e2e_integration.md`（256 kHz）と `gf180_digital_spi_proposal_20261008.md`（512 kHz）も、これに合わせて直す。

## 今回 rev の構成を決める条件（11/18）

1. **L2 の予測**：TT で 104.1 dB 以上（3 dB の余裕込み）。最悪の PVT と、ミスマッチ上位 95 % でも 101.1 dB 以上を満たす。
2. **L1 の雑音**：チョッパの折り返し、1/f、基準電圧、DAC、ジッタを含むすべての雑音源が予算内に収まる。
3. **L3 の一致**：2 つ以上の窓と 2 種類の許容誤差について、モデルとの残差電力の差が ±1 dB 以内に収まる。
4. **動作の健全性**：発振・アイドルトーン・起動失敗がなく、過入力から決めた時間内に回復する。

満たせない場合でも、その時点で最良の候補で進め、16.5 bit は予測未達と明記する。

## 評価用機能（候補、判断ゲート 1 で決める）

- **生コード出力（2 ピン）**：CIC を通さずに変調器を評価できる。
- **ADC 単体入力**：AFE をバイパスして ADC だけを測れる。
- **レジスタ設定**：チョッパ周波数、DWA のオン／オフ、AFE 利得、CIC の間引き比を切り替えられる。
