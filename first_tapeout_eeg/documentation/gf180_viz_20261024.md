# GF180 EEG チップの可視化（2026-10-24、最終のレイアウト）

最終のチップ（24fd1411、precheck 通過）の配置と配線、ブロック、雑音と歪み、回路図と抽出の比較、検証、パッド、日程、寄生込みの E2E、Bode 線図、NTF／STF、入力インピーダンスを図にした。図の文字はすべて英語。

- 図：`documentation/figures/gf180_viz_20261024_NN_*.png`（24 枚）
- スクリプト：`gf180/tapeout/viz/`
  - `extract.py`：最終の GDS とコアの LVS の結果から、ブロック、素子、最上位の配線（ネットの種類と層ごと）、長いネット、パッドの CSV と配線の画像を作る（`data/` へ）
  - `figs.py`：図 1〜15（`data/` の CSV と画像から）。雑音、歪み、比較、密度、検証、日程の CSV は、文書に記録した値を書き写したもの（出どころは `figs.py` の冒頭）
  - `figs_perf.py`：図 16〜24（`gf180/tapeout/pex/runs/e2e/` と `runs/viz/` から。E2E の数値の処理は `pex/plot_e2e.py` をそのまま使う）
  - `vizstyle.py`：色、フォント、図の枠（題、副題、注）
- 作り直し：

```bash
gf180/tools/venv310/bin/python gf180/tapeout/viz/figs.py gf180/tapeout/viz/data documentation/figures
```

```bash
gf180/tools/venv310/bin/python gf180/tapeout/viz/figs_perf.py gf180/tapeout/pex documentation/figures
```

## 図の決まり

- 白地。回路図は濃い灰色（破線）、最終の抽出は藍色（実線）、10/23 の抽出は薄い灰色。仕様と限界は赤の破線。
- ネットの種類の 8 色は色覚の違いでも区別できることを確かめた（隣どうしの ΔE の最小 10.2）。
- 対数軸には棒を使わない（棒の長さに意味がないため、点か点の対にした）。雑音は電力で足し、合計は二乗和。

## 読むときの注意

- **入力インピーダンス（23、24）はチョッパを止めた AC 解析で、参考の値。** チョッパのスイッチト・キャパシタの働きが入っていないので、チップの入力インピーダンスそのものではない。チョッパ込みの値は過渡解析で出している最中で、出たら図に菱形で足す。差動の入力は 3.3 kHz〜47 MHz で実部が負になり、Smith チャートでは |Γ| = 1 のすぐ外を通る。Z0 はチャートの正規化のための値で、100 MΩ は EEG の帯域を中ほどに置くため、50 Ω は RF の慣例。
- **AFE の帯域内の伝達（20）はブランキングを入れていない。** 高調波の和はチョッパの縁ごとの整定を数えるので、ブランキングで隠すチップの利得は数 % 高い（チョッパを止めた形の帯域内の 298.8 に近い）。
- **E2E（16〜18）は 70 µs の短い窓。** 利得の精度は数 %。相 A／B の差 18.8 mV（抽出）は、AFE のリセットを解いた直後の DC 経路の過渡（時定数 約 140 µs）で、AFE 単体では 2.02 mV p-p まで下がる。
- **DAC1 の残差の単位は「DAC1 の範囲 = 1」**（1 素子 = 1/31 = 0.032）。図 11 の「ADC のループの残差」も同じ単位（以前の「DAC の段」という書き方を改めた）。
- 図 11 の AFE の利得 297.9 は ±0.5 mV のチョッパ動作の過渡（200 µs）の値。70 µs の E2E の正弦波では回路図 291.45、最終の抽出 291.36 で、ほぼ同じ。
