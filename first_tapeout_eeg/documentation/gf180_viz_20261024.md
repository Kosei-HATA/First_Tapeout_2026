# GF180 EEG チップの可視化（2026-10-24、最終のレイアウト）

最終のチップ（10/26 の 6 回目、precheck pre_20261026。10/25 夜に 5 回目の 20de9559、10/25 昼に 4 回目の 9b5f495a で作り直し、10/24 の初版は 3 回目の 24fd1411）の配置と配線、ブロック、雑音と歪み、回路図と抽出の比較、検証、パッド、日程、寄生込みの E2E、Bode 線図、NTF／STF、入力インピーダンスを図にした。図の文字はすべて英語。

電極の DC 電流の直し（入力チョッパのクロックの結合、`gf180_pex_20261023.md` の「電極に流れる DC 電流（10/25）」）を入れた 4 回目のチップで、全部の図の元を取り直した。20、23、24 は PEX のセッション（7b00825f）、ほかはこの作り直し。

- 10：2 kHz の HD2 −127.7 → −134.1 dBc、帯域内の静的な HD2〜HD5 −165.8／−120.3／−148.9／−145.5 dBc（前 −132.7／−120.4／−160.9／−144.5）。どれも仕様 −111 dBc の内側。
- 11：AFE の残留オフセット −0.37 → −0.24 µV、リップル 2.02 → 2.38 mV p-p。12：穴埋めのあとの密度（Metal5 65.10 → 65.07 % など）。13：検証の日付と precheck のタグ。
- 16〜18：寄生込みの E2E の pex と pexchip を回し直した。AFE の出力の相 A − B が +18.8 → −2.6 mV、ADC の入力の山 −294〜+297 → −286.8〜+287.0 mV。19：AFE のループ（gmin 1e-15、4 桁まで同じ）。21、22 は ADC だけ、15 は管理表の状態が同じなので、描き直しても同じ図。
- **10/25 夜（5 回目のチップ、WN の配線抵抗の直し）**：チョッパの下の WN の Metal5 を、ゲートのレーンの通路の上に戻した（`gf180_pex_20261023.md` の「WN の配線抵抗の直し」）。07〜09、11、12 を描き直した：WN の W 0.570 → 0.354 Ω、両側 1.32 Ω・1.47 nVrms、配線抵抗込みの AFE の雑音 5.049 nVrms、総残差 6.05 nVrms（16.46 bit）、リップル 2.37 mV p-p、Metal5 の密度 65.09 %。13 は Magic DRC の行（ダミー COMP と Poly2 の穴埋めを除いた形。COMP だけでは Magic の不具合で落ちるようになった）。01〜06、14、15 はチップの最上位の配線も同じで、同じ図。10 と 16〜24 も 10/26 朝に 5 回目の抽出で回し直して描き直した（歪み、寄生込みの E2E、`viz_data.py` の AFE の組。どれも 4 回目とほぼ同じで、値は `gf180_pex_20261023.md` の「WN の配線抵抗の直し」）。

## 図の決まり

- 白地。回路図は濃い灰色（破線）、最終の抽出は藍色（実線）、10/23 の抽出は薄い灰色。仕様と限界は赤の破線。
- ネットの種類の 8 色は色覚の違いでも区別できることを確かめた（隣どうしの ΔE の最小 10.2）。
- 対数軸には棒を使わない（棒の長さに意味がないため、点か点の対にした）。雑音は電力で足し、合計は二乗和。

## 読むときの注意

- **入力インピーダンス（23、24）の線はチョッパを止めた AC 解析で、参考の値。** チョッパのスイッチト・キャパシタの働きが入っていないので、チップの入力インピーダンスそのものではない。図 20・23・24 は 10/25 に、4 回目のチップ（9b5f495a）の抽出と ngspice の gmin 1e-15 で描き直した。
  - チョッパ込みの値は菱形（過渡解析、`gf180/tapeout/pex/runs/viz/afe_zin.csv`）。並列の形にすると、回路図の差動は −578 kΩ ∥ 28.5 pF、最終の抽出の差動は +3.5 MΩ ∥ 36.2 pF、同相は片側 87／60 MΩ ∥ 138／133 pF（5 回目のチップ。4 回目は同相 61 MΩ）。
  - 回路図の差動が負の抵抗になるのは、CPF_TRIM 8 で Cpf の正帰還が Cin のスイッチト・キャパシタの電流を 1 % 打ち消しすぎるため（抽出は 0.2 % 足りない側）。
  - 線の差動の実部は 168 Hz〜47 MHz（抽出。回路図は 220 Hz〜50 MHz）で負になり、Smith チャートでは |Γ| = 1 のすぐ外を通る。以前の「3.3 kHz から」は、ngspice の既定の gmin（素子の M 倍）の漏れが低い周波数の実部を隠していたため。
  - Z0 はチャートの正規化のための値で、100 MΩ は EEG の帯域を中ほどに置くため、50 Ω は RF の慣例。チョッパ込みの差動（0.5〜3.5 MΩ）は Z0 = 100 MΩ よりずっと小さいので、左の端（Γ ≈ −1）に集まる。
- **AFE の帯域内の伝達（20）の線は、ブランキングを入れていない高調波の和。** チョッパの縁ごとの整定を数えるので、回路図 287.2、最終の抽出 284.8 になる。
  - 菱形のブランキングありの過渡は、回路図 299.07（100 Hz〜16 kHz、50 kHz で 299.57）、最終の抽出 298.94（1 kHz）。和より 4.0／4.7 % 高く、チョッパを止めた形の帯域内の |H|（299.2／298.8）とほぼ同じ。50 kHz まで平らで、位相は 89 ns の遅れと同じ形。
  - E2E の AFE の利得 291.5（16 kHz）は周期平均の値で、299.11 × sinc(16 kHz × 7.8125 µs) = 291.5 と合う。
- **E2E（16〜18）は 70 µs の短い窓。** 利得の精度は数 %。相 A／B の差 −2.7 mV（抽出、5 回目のチップ。4 回目 −2.6 mV）は、AFE のリセットを解いた直後の P／N の不釣り合いが抜けていく起動の過渡（窓の中の当てはめで時定数 約 100 µs）で、AFE 単体では 2.37 mV p-p まで下がる。3 回目のチップでは +18.8 mV（時定数 143 µs）で、その大きさは入力チョッパのクロックの結合の WP／WN の差で決まっていた。
- **DAC1 の残差の単位は「DAC1 の範囲 = 1」**（1 素子 = 1/31 = 0.032）。図 11 の「ADC のループの残差」も同じ単位（以前の「DAC の段」という書き方を改めた）。
- 図 11 の AFE の利得 297.9 は ±0.5 mV のチョッパ動作の過渡（200 µs）の値。70 µs の E2E の正弦波では回路図 291.45、最終の抽出 291.34 で、ほぼ同じ。
