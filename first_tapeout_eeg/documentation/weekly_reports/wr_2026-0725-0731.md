# ミーティング

## 07/30 週次定例会

### 1. チーム体制と運用ルール
- **新メンバー参画**: HiICSさん側のチームメンバー追加。アナログ回路設計の専門的知見をご共有いただく。
- **運用方法**: 定例ミーティングの前に進捗共有および週報提出を行うフローを統一。
- **レイアウト検証**: アンテナエラーの抑制目標・許容基準について共有。

### 2. システム仕様と数値目標の整理
製品レベルの要求仕様とプロセス側の制約を整理し、定量的な数値目標を明確化することを確認。

- **脳波（EEG）信号ターゲットパラメータ**:
  - **信号振幅**: 数十 〜 数百 \(\mu\text{V}\)
  - **通過周波数帯域**: 0.5 Hz 〜 40 Hz
  - **目標ADC解像度**: 約 24-bit
- **システムモデリング・検証アプローチ**:
  - MATLAB や LTspice によるビヘイビアモデルを構築し、システム全体系の周波数特性やノイズ挙動を抽象度を上げて可視化・シミュレーションするアプローチを検討。
  - 差動ADCへの接続性を踏まえたフィルタ構成の最適化。
  - Opamp および ADC の基本スペック向上と、Caravel 評価ボード側での実現可能スペックの検証。

### 3. First Tapeout に向けた開発戦略
- **SkyWater 130nm プロセスの活用**:
  - SkyWater 130nm 汎用 PDK モデルを用いてシミュレーション・設計を進める。
- **段階的（アジャイル）開発アプローチ**:
  - 入出力（I/O）インターフェースを明確にしつつ、まずは最小限のロースペック構成で全フロー（回路〜GDSII）を一通り通すことを最優先とする。
  - コアとなる高精度ADC・Opampブロックの活性化と性能評価を段階的に実施。
