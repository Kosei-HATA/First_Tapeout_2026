# Pythonによる全体系動作シミュレーション (`eeg_soc_sim.py`)

アナログフロントエンド（AFE）からデシメーション・デジタルシリアル転送（SPI）までの動作をシミュレートするPythonモデル（[`eeg_soc_sim.py`](file:///Users/noah/codings/first_tapeout_2026/first_tapeout_eeg/source/trials/20260806/eeg_soc_sim.py)）を構築し、波形・数値を検証した。

![Block Waveforms](file:///Users/noah/codings/first_tapeout_2026/first_tapeout_eeg/source/trials/20260806/block_waveforms.png)

### モデリング条件とパラメータ設定
1. **入力EEG＆ノイズモデル**:
   - 脳波基本波（8Hz等）、高次成分、低周波ドリフト（8 µV @ 0.2 Hz）をモデル化
   - 50 Hz の同相モード雑音（200 µV）および電極独立雑音 \(\mathcal{N}(0, 2\,\mu\text{V})\) を付加
2. **アナログフィルタ・PGA**:
   - 1次HPF (0.5 Hz) と 1次LPF (30 Hz) により同相雑音および高周波ノイズを低減
   - PGA（プログラマブルゲインアンプ）により1000倍に増幅（µVオーダーから ±18.3 mVの差動信号へ変換）
3. **ΣΔ-ADC & デシメーション**:
   - 変調クロック \(f_{\text{mod}} = 16\,\text{kHz}\)、差動フルスケール \(\pm 50\,\text{mV}\)
   - 1次1bit \(\Sigma\Delta\) 変調器を適用後、\(\text{OSR} = 64\)（64点平均）によりデシメーションを実施し、最終サンプリングレート \(f_{\text{out}} = 250\,\text{Hz}\) を実現
4. **デジタル出力・SPIデータ伝送**:
   - int16の量子化コードにチャンネル情報・ステータスを含む24bitフレームを構築
   - 必要転送レートは 6000 bps となり、1 MHz の SPI クロックで十分に伝送可能であることを確認

# ΣΔ変調器および入力信号の検証（森脇）

- ビヘイビアレベルのシミュレーションと並行し、森脇にて回路レベルでの ΣΔ 変調器および入力信号に関するシミュレーション・検証を進行中。
- ビヘイビアモデルで算出した数値目標（PGA出力レンジ ±18.3 mV、フルスケール ±50 mV等）との対比・整合性を検証している。
