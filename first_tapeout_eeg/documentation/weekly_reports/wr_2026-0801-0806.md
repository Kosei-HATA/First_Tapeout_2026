# Pythonによる全体系動作シミュレーション (`eeg_soc_sim.py`)

アナログフロントエンド（AFE）からデシメーション・デジタルシリアル転送（SPI）までの動作をシミュレートするPythonモデル（[`eeg_soc_sim.py`](file:///Users/noah/codings/first_tapeout_2026/first_tapeout_eeg/source/trials/20260806/eeg_soc_sim.py)）を構築し、波形・数値を検証した。

![Block Waveforms](file:///Users/noah/codings/first_tapeout_2026/first_tapeout_eeg/source/trials/20260806/block_waveforms.png)

### モデリング条件とパラメータ設定
1. **入力EEG＆ノイズモデル**:
   - 脳波基本波（8Hz等）、高次成分、低周波ドリフト（8 µV @ 0.2 Hz）をモデル化
   - 50 Hz の同相モード雑音（200 µV）および電極独立雑音 \(\mathcal{N}(0, 2\,\mu\text{V})\) を付加
2. **アナログフィルタ・PGA**:
   - 1次HPF (0.5 Hz) と 1次LPF (30 Hz) により同相雑音および高周波ノイズを低減
   - PGA（プログラマブルゲインアンプ）により1000倍に増幅（µVオーダーから ±18.3 mVの差動信号へ変換）
3. **ΣΔ-ADC & デシメーション**:
   - 変調クロック \(f_{\text{mod}} = 16\,\text{kHz}\)、差動フルスケール \(\pm 50\,\text{mV}\)
   - 1次1bit \(\Sigma\Delta\) 変調器を適用後、\(\text{OSR} = 64\)（64点平均）によりデシメーションを実施し、最終サンプリングレート \(f_{\text{out}} = 250\,\text{Hz}\) を実現
4. **デジタル出力・SPIデータ伝送**:
   - int16の量子化コードにチャンネル情報・ステータスを含む24bitフレームを構築
   - 必要転送レートは 6000 bps となり、1 MHz の SPI クロックで十分に伝送可能であることを確認

# Xschem回路 & PEX（寄生成分抽出）シミュレーション検証

実レイアウト（ALIGN生成 `opamp_adc.gds`）と理想回路（`1samp_opamp_adc.sch`）の乖離を把握するため、PEX抽出フローを構築し、特性比較を行った。

### 1. PEX検証環境の構築
- **寄生成分抽出の自動化 (`ext2pex.py`)**: Magic の `.extDB`（基板容量・結合容量）から階層名を再帰解決し、PEX Spiceネットリスト（`opamp_adc_pex.spice`）を自動生成するフローを確立。
- **PEXテストベンチ構築**: 理想回路と同一の帰還（\(R_1=99\,\text{k}\Omega / R_2=1\,\text{k}\Omega\)）で駆動するテストベンチ（`1samp_opamp_adc_pex.sch`）および比較プロット自動生成環境を用意。

### 2. 理想回路 vs PEX実レイアウトの特性比較結果
| 評価項目 | 理想回路 (.sch, \(L=0.5\,\mu\text{m}\)) | PEX実レイアウト (ALIGN生成, \(L=0.15\,\mu\text{m}\)) |
| :--- | :--- | :--- |
| **開ループ利得 \(A_0\)** | **~56 dB** (601x) | **~32 dB** (38x) |
| **閉ループ利得** | **38.7 dB** (86x) | **28.7 dB** (27x) |
| **\(V_{\text{out}}\) 振幅** | **0.27 ～ 1.13 V** | **0.54 ～ 0.81 V** |
| **1bit ADC出力 (\(D_{\text{out}}\))** | **反転（正常動作）** | **1.8 V に張り付き（不動作）** |

### 3. 要因分析と今後の改善論点
- **不動作の直接原因**: 実レイアウトで素子のチャネル長が \(L=0.15\,\mu\text{m}\)（最小長）となっているため、オペアンプの利得が大幅に不足。結果として \(V_{\text{out}}\) がコンパレータ閾値（\(0.9\,\text{V}\)）を超えられず、1bit ADCとして正しく動作しないことを特定した（\(V_{\text{bias}}\) 調整では解決不可）。
- **今後の対策方針（改善論点）**:
  1. **オペアンプゲインの改善**: チャネル長の長い素子（例: \(L \ge 0.5\,\mu\text{m}\)）への変更・再配置によるオペアンプ利得の向上。
  2. **仕様の見直し**: コンパレータの閾値およびゲイン要求仕様の再検討。
