- **設計点を f_chop=8 kHz → 1 kHz に変更**（下記「設計判断」）、clkgen RTL も 1 kHz 化・iverilog 検証済み
- Rf 帰還（疑似抵抗・2–30 GΩ）および PFL（ポジティブ帰還容量 0.3–1 pF）を検証し、それぞれ β 崩壊・4–8 Hz 共振により却下

## 「信号消滅」問題の全容
症状: 8 Hz 信号が起動後 ~80 ms で消え、出力差動が 0 に落ちる。切り分けの経緯:
1. `save`・クロック構成・nodeset のいずれも無罪（対照ランで確認）
2. 内部ノードプローブで入力ピン INP/INN が 0.9 V → 1.75 V（レール）へ ~100 ms で上昇し、入力対の同相範囲を外れることを特定
3. 当初はチョッパの電荷注入ポンプと診断し、TG への A 側ダミー追加・ゲート側ブリード抵抗・DC サーボ（CM/diff 両 DSL）を設計・実装
4. **真因はベンチの `VPHI PULSE({VDD} 0 ...)` の v1/v2 反転**と判明: PHI/PHIB が半周期同時 ON（入力 4 ノード短絡で差動消滅）・半周期同時 OFF（ゲート浮遊→復調チョッパの転流が Cgd 経由でゲートをポンプ）していた
5. 正クロック＋疑似抵抗のみで INP=0.9000 V が 200 ms 完璧に安定し、8 Hz 信号が持続することを確認
6. DSL は実回路の堅牢性としては有効だったが、雑音（シンク NMOS の雑音電流×高 Z ゲートノード）と複雑性の観点から全撤去。回路ファイルは `eeg_fd_ota_chopped_full2.spice`（DSL 無し）が正規、DSL 版は `eeg_fd_ota_chopped_full2_dsl_archive.spice` に保存

## −22 % ゲイン欠損の解析と設計点変更
- 遅延スイープ（復調 ±16 µs、5+3 点）: τ=0 が局所最大で位相トリムでは回復不可と確定
- 周波数掃引（1/4/8/40/100 Hz）: ゲインが 5.1→25.0→31.6 と立ち上がる HP 特性（fc≈5 Hz）
- 16 kHz ランで fc が約 2 倍化 → **fc ∝ f_chop**（チョップ帰還のスイッチドキャパシタ抵抗 × Cin が作る固有コーナー、fc ≈ f_chop/(πG) 系）
- 2 段 Miller 構成の制約（GBW≈4.6 MHz、第 2 極 ~9.5 MHz）から、f_chop=8 kHz では fc≤0.5 Hz と雑音仕様は構造的に両立不可
- **f_chop=1 kHz を採用**（四重の利点）:
  - fc≈1.3 Hz（実測）、8–40 Hz は ±1 % 以内
  - 段 1 ポール（600 Hz）より下なので A1(f_chop) が増え、復調後段の 1/f 雑音抑制が改善
  - 帯域内雑音 ≈ 38.6 nV/√Hz → **0.38 µVrms（規格 1.0 µVrms クリア）**
  - 1 kHz リップルは CIC デシメータのノッチ（250/500/1000 SPS の整数倍）に一致
- 却下した代替案: Rf 帰還（2–30 GΩ: チョップ入力 Z との分圧で β 崩壊、全周波数で悪化）、PFL（0.3–1 pF: 1 Hz は回復するが 4–8 Hz に +37〜63 % の共振バンプ、共振を帯域外に出すとリフト量不足）
