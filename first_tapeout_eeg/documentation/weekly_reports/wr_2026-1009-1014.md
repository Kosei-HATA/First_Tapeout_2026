## 今週の概要と前回からの差分

## chain2/3/4：フルチェーン完走までの経緯

- **chain2 死亡（10/8）**: seg4（global 161.25..215.00 ms）が local 15.63 ms で tts 死（`bnopn19#branch`、int2 側）。
- **chain3（10/11〜12）**: seg4 を 13.4375 ms×4 チャンク（seg41-44）に分割し、死亡点を含む seg42 のみ method=gear で通過。seg4 merge まで完了したが、続く seg5（フル長）も local **15.6289 ms** で tts 死（`bnopn14#branch`、int1 側、10/12 16:12）。
- **ハザードの同定**: seg4/seg5 ともにセグメント先頭から ~15.63 ms で死亡。32 Hz 入力信号の半周期（15.625 ms）と一致する**周期的な収束ハザード**と確定。
- **chain4（10/12〜14）**: seg5/seg6 をそれぞれ 4 チャンク化し、ハザードチャンク（seg52/seg62）のみ gear、残り trap で運用。全 8 チャンクを tts=0 で完走し、10/14 05:48 に全 6 セグメント連結 + SNDR 自動解析が完了（FULL CHAIN DONE）。
- 各 merge 後にチャンク csv を削除する housekeeping を徹底（計 ~17.7 GB を確保）。監視は 10 分間隔のバックグラウンドワッチャー + 完了見込み時刻のワンショットタイマーで自動化。

## フルチェーン確定値と 6bit A/B 判定

**5bit 無ディザ フルチェーン（chain4、10/14 確定）**:

- TT・322.5 ms・10 コヒーレントサイクル・32 Hz 0.6 FS・fs=512 kHz・PH2 プラトー多数決読み出し
- **SNDR = 72.11 dB（ENOB 11.7）**、信号振幅 0.6261、mean code 0.5000
- 帯域内トップは 41.6 Hz（8e-05）ほか LC スカート群、3.2 Hz 基本波も残留
- 4bit フルチェーン（72.74 dB、10/6）と同水準 — 多ビット化はフルレコード性能を改善しない

**6bit スクリーン A/B（10/12 確定）**:

- 35 ms・1 コヒーレントサイクル・同一解析で **SNDR = 102.96 dB**
- 5bit ベースライン（110.68 dB）を −7.7 dB 下回り、棄却線（≲110 dB）を下抜け → **6bit 化棄却**
- 行為モデルの +11.7 dB 窓改善予測は SPICE に転移せず。「SPICE のワンダリングは行為モデルより相関時間が長く、フルレコード予測に行為モデルを使えない」という既知の警告と整合

## 結論：ENOB 天井の確定と今後の方向

- 消化済みレバー: 多ビット化（5/6bit）、入力サインディザ、量子化器ディザ（減算/非減算）、κ 掃引、3 次化、768 kHz 化 — 全て棄却
- 残余床は一様な k·3.2 Hz リミットサイクルコムで、トーン実現はループ摂動にカオティック。**天井 72-73 dB（ENOB ~11.7）が現アーキテクチャの定量限界**
- 110 dB 超には loop 力学を変える構造再設計が必要： ループタイミング/係数再設計（sky130 で 92→101 dB の実績）、アンチヒステリシス比較器、CT 2 次化
- ただし **システムのノイズ仕様（1.0 µVrms）は現構成で 3.1 倍のマージンを保持**しており、本テープアウトには十分。スペックアップは次 rev の研究投資として位置づける
- 全結果は `documentation/gf180_feasibility.md` に記録済み。データは `gf180/results/sdm3_mb5_512k_full_chain.csv.gz`（4.7 GB）と seg1-6 各 gz に保管
