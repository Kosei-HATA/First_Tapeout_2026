# MOSCAP初期化の段階対照
元モデルの式は不変。安定化抵抗追加、容量線形化、AFE要素の削除なし。一次14条件＋top追加2条件、各30秒上限。

## 結果
- 単NMOSCAP＋1kΩ、0.85V: gearのOP開始は1µs完了。gearのUIC/ramp、trapのOP/UIC/rampは30秒上限。時間上限は未解決でありモデル不正の証明ではない。
- bias単体: OP開始はgear/trapともMOSCAP内部E枝で直ちに失敗。UICと電源ランプは両solverで2µs到達。
- AFE全top: OP開始は両solverで約0.156psに失敗。
- topのgear UIC/100ns電源ランプは0.5µsに到達、壁時計8.07/5.59秒。128kHzの1周期未満で、利得・定常性は未評価。
- biasのOP VBN=0.84610153V、2µs後UIC=0.85096381V、ramp=0.87856278V。到達や電圧の近さだけで正しい定常状態とは判定しない。
- ランプ試験は初期化診断。参照源/制御の電源順序認定ではない。

## 解釈
元C(V)式は滑らかなtanhで、固有の代数的不連続は見つかっていない。生成E源の状態初期化・数値条件が関与する仮説は対照結果と整合するが、特定ソースコード不具合への断定はしない。UICは修正や合格の代用ではない。
