# 実バイアス回路の起動・追従検証

対象は元プロジェクトとSHA-256が一致する eeg_bias.spice です。元GDS・ソースは変更していません。物理GDSとの回路対応は別途実施されたコアLVSを前提にします。

## 実施・結果

- 電源3.0/3.3/3.6 Vと typical/27℃、SS/85℃、FF/−20℃、SF/27℃、FS/27℃の15条件でDC動作点を計算。
- 各条件で1/10/100 µsの電源ランプを実施し、ランプ後100 µsまで計算。計45ケースで、出力電圧11点と負荷電流3点の最終値が同条件DC値の2%以内。最大相対差は0.042731%。2%は今回の収束確認用の診断基準であり、製品の精度仕様ではありません。
- デジタルtrim入力のHighは電源に追従させました。AFE bias code=2、boosterはリセット時相当の4単位。
- ADCクロックの4個の理想バイアス電圧源を実bias回路に置き換え、実OTA負荷と組み合わせて15条件を再計算。全条件で位相切替marginが正。最小0.143513 nsは3.6 V、FF/−20℃。最小許容guardbandの製品仕様は未定義です。
- 全試験で検出したシミュレーションエラーなし。モデルに元からあるsubckt multiplierの警告は記録されています。

## 残る制約

VREFP/VREFNは理想1.9/1.4 V、ITST試験負荷は1 Vを維持しています。reference回路そのものの起動、電源順序、無電源時の外部端子条件を完全再現していません。起動試験は代表ミラー負荷によるstand-alone bias、ADCクロック試験はDC動作点から開始するため、全チップ電源投入からクロック動作までを一体で検証したものではありません。

MOSCAPは既存ベンチの線形近似です。PEX・配線/パッケージ寄生、全trimコード、brownout、電源再投入、ばらつき/Monte Carlo、ADC/DAC閉ループ精度は対象外です。今回の合格は記載した診断基準内での結果で、製造承認やENOB保証ではありません。

- run_bias_validation.py: 再現用。既存コンテナーで python3 /work/Test-2-4/manufacturing_preflight/bias_validation/run_bias_validation.py。再実行はこの検証フォルダー内の結果を更新します。


## MOSCAPモデルの適用範囲（追補）
45件の起動試験、実bias付き15/75条件クロック試験はmoscap_lin.spiceの線形定数C近似です。公式MOSCAPの電圧依存モデルによる動作成立を示しません。回路ソースや配線の一致とモデルの一致は別です。元デッキ・波形・数値結果は変更していません。
