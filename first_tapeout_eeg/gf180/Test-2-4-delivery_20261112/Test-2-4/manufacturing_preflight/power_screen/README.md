# Test-2-4 DVDD電源ECOの静的スクリーニング

## 結論

4本のMetal5ブリッジの寸法と公開PDK値から、限定的な抵抗・電流幅換算は可能です。ただし実DVDD負荷、各ブリッジの分流、接合温度、既存ビア電流が未測定であり、全PDNのEM/IR合格ではありません。

## 抵抗の一次元計算

導入済みMagic techのM5値は、公称40mΩ/□、低抵抗corner31mΩ/□、高抵抗corner49mΩ/□です。techは単位をmilliohms per squareと明記しています。

R=Rs×L/Wを使用すると、幅10µm、空隙2µm部分の各ブリッジは6.2/8.0/9.8mΩ（low/nominal/high）です。描画全長4µmを同じ一次元矩形として扱う値は12.4/16.0/19.6mΩです。これは端子をどこに取るかに依存する近似であり、拡がり抵抗・電流集中を含む上下限ではありません。

仮に1本へ10mAが流れる場合、空隙部分だけの電圧降下は62/80/98µVです。この10mAは説明用の仮定で、測定したDVDD電流ではありません。4本が完全に等分流する理想値もJSONに記録しましたが、実配線の分流確認なしに使えません。高抵抗corner値は温度補償済み値という意味ではありません。

## 公開EM値の幅換算

GF180設計手引き14.2の11kÅ top-metal一方向電流規定から、10µm幅1本あたりの単純換算は85℃で45mA、110℃で22mA、125℃で15mAです。4本分を無条件に合算した許容チップ電流とはしません。

0.26µmビアの一方向電流値は1カット当たり85/110/125℃で0.58/0.28/0.18mAです。今回の空隙に新ビアはありませんが、既存の供給経路のビアが別の制限になり得ます。既存カット数・分流を確認していないため、ビア余裕の合否は出していません。

出典: https://gf180mcu-pdk.readthedocs.io/en/latest/physical_verification/design_manual/drm_14_2.html （2026-11-11確認）。EM値は同ページの寿命・温度・電流定義に依存し、今回の製造条件への適用は製造側確認が必要です。

## 既存電流試験の扱い

functional/bias_op.logにはバイアス部分回路799～1271µA、functional/afe_actual_bias.logにはAFE部分回路23.42～24.73mAの測定があります。これらはアナログ部分試験であり、DVDD電流として使ったり、重複の可能性を無視してチップ電流に合算したりしていません。

## 次に必要なもの

- DVDDの平均・過渡電流と動作モードを含む負荷モデル
- 電源幹線・既存ビア・パッドを含む分流/抵抗網
- 接合温度とパッケージ/電源インピーダンス
- 電流集中、IR drop、温度を含むEM評価

計算値と仮定はpower_screen.json、再現はcalculate_screen.py。GDS、PDK、既存検証結果は変更していません。
