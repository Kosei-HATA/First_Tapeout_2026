# DVDDブリッジ周辺の実GDS幾何監査

対象: Test-2-4.gds（SHA-256はlocal_geometry.json）。元GDSは変更していません。全チップ抽出は行わず、指定局所領域だけを階層走査しました。約8秒で完了しました。

## 実測した構造

- 東側DVDDの2供給点: 各M2→M5スタックは6×72.28µm。
- 各供給点のVia2、Via3、Via4はそれぞれ1,160カット（10列×116行）。全カット0.26×0.26µm。座標重複を除いて数え、元出現数と一致しました。
- 各スタック領域はM2/M3/M4/M5すべてで金属欠損0。
- パッド側M2断面は6本の指状配線。幅9.5µmが2本、10.25µmが4本、合計60µm。
- x=3521µmのM5断面では、追加した10µm幅4本だけが2µmスロットを横断。ブリッジの金属欠損0、空隙部分のVia4は0。
- 外側幹線の8か所のtie分岐は4×4µmのM4/M5アンカー、各Via4は36カット（6×6）、金属欠損0。
- 内側幹線の西側x=3499.5µmでは、6µm幅1本、10µm幅4本、6.5µm幅4本のM5接続を観測。ソースのdigital strapとdecap接続位置に対応します。

## 電流分配を仮定しない評価

部位別の幅換算は可能です。例として125℃の公開一方向EM表では、M5の10µmブリッジ1本15mAに対し、6µmの横ストラップは9mAです。小さい枝があることは分かりますが、担当負荷が違うため、それだけで設計のボトルネックや違反とは判断できません。

1,160ビアの規定値合計は125℃で208.8mA/層/供給点、36カットのtieアンカーは6.48mAです。これは各カットが規定以内という条件から導く合計電流の必要条件であり、実際にその電流を供給できる保証でも均等分流の仮定でもありません。電流集中により1カットが先に制限へ達し得ます。異なる直列via層の許容値を合算していません。

注意: ビアスタックの「6µm」はx方向寸法です。パッドからの電流は横方向・上下分布で流れるため、これを一律6µm幅の電流ボトルネックとして扱うのは不適切です。パッド側M2指の個別幅とvia配列を記録し、抵抗網による評価へ渡せる状態にしました。

M5スロット断面は局所幾何の確認であり、他層を通る全代替経路の不存在証明ではありません。既存296点導通PASSは参照しましたが、電流分布や全PDN抵抗網の再計算は行っていません。

## 判定と次段階

この監査からEM/IR合格は出しません。実DVDDの平均/過渡負荷、温度、幹線・ビア・pad内部の抵抗網が必要です。局所構造に予想外のカット不足や金属欠損は見つかりませんでしたが、pad内部・全リング・各digital macroのvia経路は今回の範囲外です。

再現: iic-osic-toolsコンテナ内で inspect_local.py を実行。summarize_screen.py はWindowsの既存パスを使い、数値集計を再生成します。結果はlocal_geometry.jsonとbottleneck_screen.json。EM出典・元の抵抗評価は親フォルダーのREADME.md、power_screen.jsonを参照してください。
