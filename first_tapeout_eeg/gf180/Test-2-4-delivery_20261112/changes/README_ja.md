# Test-2-4 修正箇所の実GDS比較図

このフォルダーの4枚のPNGは、SHA-256を固定した実GDSをKLayoutで読み、ブーリアン差分を計算して描画したものです。画像生成AIによる模式図ではありません。元GDSは変更していません。

## PNGの読み方

1. `01_change_locations.png`: 全体位置図。元版からTest2-3へ追加したDVDD橋B1～B4と、Test2-3からTest-2-4へ変更した72個のBondpad配置を区別しています。灰色は既存Metal5の背景、紫の枠はpad修正位置、緑の丸は橋の位置を示す注記です。すべてのチップ層を表示した図ではありません。
2. `02_dvdd_bridges_before_after_diff.png`: 4か所のDVDD橋について元版／修正版／追加差分を並べています。Metal5（81/0）、チップ全体の座標です。この橋はTest-2-4にも変更なく継承されています。
3. `03_pad_layers_before_after_diff.png`: Bondpad_5LMのM2（36/0）・M3（42/0）・M4（46/0）を別々に比較しています。Test2-3／Test-2-4／追加差分の順です。元版の当該pad形状はTest2-3と同一です。座標はpadセル内のローカル座標です。
4. `04_pad_notch_detail.png`: 図3の橙色点線枠、x=4～14 µm・y=10～20 µmを拡大したものです。図3と同じ3層、同じ前後比較です。

図2～4では、青灰色が既存の金属、緑が追加した金属、差分図の薄灰色が元形状の参考表示です。寸法はµm（図ではum）、面積はµm²（図ではum2）です。前後・差分は同一範囲、x/y等倍率で表示しています。位置を示す枠・丸・矢印・尺度バーは注記でありGDS図形ではありません。

## 実測結果

### DVDD橋: 元版 → Test2-3、Test-2-4へ継承

- 層: Metal5、81/0。
- 追加した長方形: 各x=3519～3523 µm、y範囲はB1=596.86～606.86、B2=655.14～665.14、B3=2006.86～2016.86、B4=2065.14～2075.14 µm。
- 各4×10 µmの長方形は左右の既存配線へ1 µmずつ重なります。
- 既存金属と重ならない新規領域は各2×10=20 µm²、4か所合計80 µm²です。削除0 µm²。
- 2 µmのスロット全体を埋めたのではなく、4か所だけを局所的に接続しています。
- Test2-3とTest-2-4のMetal5は全チップのブーリアン比較で差分0です。

### Bondpad_5LM: Test2-3 → Test-2-4

- 対象セル72配置。M2/M3/M4とも追加のみで削除なし。
- M2: セル当たり561.6000 µm²、全チップ40,435.2000 µm²。
- M3: セル当たり555.1416 µm²、全チップ39,970.1952 µm²。
- M4: セル当たり555.1416 µm²、全チップ39,970.1952 µm²。
- 全チップの実差分が、ローカル差分を全72配置へ変換した図形と完全に一致することを確認しています。
- M2/M3/M4以外の図形、配置、階層、文字、プロパティは元のままです。ビア、PAD開口、Metal5も変更していません。

## 根拠と再現

- `render_gds_comparisons.py`: 読取・差分検証・描画を行う再現スクリプト。入力GDSを保存／上書きしません。
- `geometry_extract.json`: 描画に使った橋とpadの正確なポリゴン頂点、穴、表示領域、72配置の座標変換と階層。
- `metadata.json`: 入力3版のパス・サイズ・SHA-256、ツール版、面積、検証結果。
- `changed_areas.csv`: セル／全チップの差分面積。
- `SHA256SUMS.txt`: 入力GDSと同梱ファイルのハッシュ。
- `visual_qa.json`: 最終PNGの目視・寸法確認記録。

既存のDocker環境（`gf180-audit-20261029`、`/work`マウント）での再現例:

```text
docker exec -e MPLBACKEND=Agg gf180-audit-20261029 python3 /work/Test-2-4/delivery_visuals_20261112/render_gds_comparisons.py
```

KLayout 0.30.9、Matplotlib 3.11.0を使用しています。入力GDSの相対配置とハッシュが一致する環境が必要です。再実行すると、このフォルダー内の生成図・差分メタデータを更新します。図のレイアウトを変更した場合は目視確認も再実施してください。

## 注意

この資料は設計変更の可視化と図形差分の検証です。製造投入、CUP完全適合、機械的ボンディング、ESD、EM/IR、電流容量などの承認を意味しません。標準Bondpad_5LMを変更したカスタム形状であり、詳細な検証範囲・未解決事項は統合レポートと既存verification/manufacturing_preflight資料を参照してください。
