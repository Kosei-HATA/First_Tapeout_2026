# アルゴリズム検証

## データセット

テスト用データには[PocketSDR](https://github.com/tomojitakasu/PocketSDR)のサンプルデータを利用した。PocketSDRはGNSS用フロントエンドIC(MAX2771)とUSBコンバータICを組み合わせたデバイスで、GNSSのベースバンド信号をコンピュータに収録することができる。PocketSDRで使用しているフロントエンドICは本プロジェクトでも使用することを予定しているため、検証用のサンプルデータとして使用することに適している。

データセットはIF=2MHz、サンプリング8MHz、I信号のみの```L1_20220114_004440_8MHz_I.bin```を使用した。

## 初期信号探索

### 概要

初期信号探索のアルゴリズムは[拙著](https://qiita.com/pochiMasahiro/items/a3bcd44ef5a9469a3e03)を参照。

データセットはIF周波数2MHzでミキシングされたI信号のみなので、IQ信号に変換しつつベースバンド信号までダウンコンバージョンする必要がある。その信号処理を記述して、拙著の信号探索アルゴリズムに接続してGPS信号を検出できるか検証する。

### IF信号からベースバンド信号への変換

サンプリング周波数がIF信号の4倍のとき、計算が効率化できる。サンプリング周波数$f_s$のとき、サンプリング時刻は$t_n=n/f_s$と表せる。これを用いて、ローカル発振器の位相$\theta_n$はIF周波数を$f_{IF}$とすると、
$$
\theta_n = 2\pi f_{IF}/f_s
$$
となる。今、$f_s=4f_{IF}$なので、
$$
\theta_n= 2\pi \frac{f_{IF}}{4f_{IF}}=\frac{\pi}{2}n
$$
となる。IQ信号はIF信号に$f_{IF}$のIQの信号を掛け算するので、$n=0 \sim 4$の範囲で$\theta_n$を考えると下記のようになる。

| n   | $\theta_n$       | $I_{mix}=\cos \left( \frac{\pi}{2}n \right)$ | $Q_{mix}=-\sin \left( \frac{\pi}{2}n \right)$ | 
| --- | ---------------- | -------------------------------------------- | --------------------------------------------- | 
| 0   | 0                | 1                                            | 0                                             | 
| 1   | $\frac{\pi}{2}$  | 0                                            | -1                                            | 
| 2   | $\pi$            | -1                                           | 0                                             | 
| 3   | $\frac{3}{2\pi}$ | 0                                            | 1                                             | 
| 4   | $2\pi$           | 1                                            | 0                                             | 

したがって、I信号は偶数インデックスのときのみ、1倍または−１倍し、Q信号は奇数インデックス時のみ1倍または-1倍する。それ以外のインデックスでは0となる。

これを実装すると下記のようになる。コードはpythonである。

```
def readdata(f_name, start, num_sample):
    # IFデータの読み込み
    x = np.fromfile(f_name, dtype=np.int8, count = num_sample, offset = start)

    samples = len(x)
    print("Loaded {0:.1f} ms".format(samples/fs*1000))

    x_even = x[0::2]
    x_odd = x[1::2]

    num_sample = len(x_even)

    i_tmp = np.zeros(num_sample).astype(np.int8)
    q_tmp = np.zeros(num_sample).astype(np.int8)

    i_tmp[0::2] = (+1)*x_even[0::2]
    i_tmp[1::2] = (-1)*x_even[1::2]

    q_tmp[0::2] = (-1)*x_odd[0::2]
    q_tmp[1::2] = (+1)*x_odd[1::2]

    samples = samples // 2

    return (samples, i_tmp, q_tmp)
```

はじめにIFデータを読み込む。```np.fromfile```はバイナリファイルを```dtype```で指定した型の```ndarray```として読み出すメソッドである。```x_even```がI信号に、```x_odd```がQ信号に対応する。```x[0::2]```として、1個飛ばしで読み出すため、全体の長さは1/2になり、また、8MHzから4MHzにデシメーションしたことになる。

```x_even```と```x_odd```に分けたものを１個飛ばしで読み出して、-1倍または1倍することで、IQ信号への変換とダウンコンバージョンが実現される。
